PANORAMIC : CREER UN OBJET

Comment créer un objet système dans PANORAMIC_EDITOR

On tape son type suivi d'un numéro : chaque objet système (c'est à dire créé par le système d'exploitation Windows) possède un numéro défini à sa création et ce numéro sera utilisé pour toute action sur cet objet.

Par défaut, tout objet est créé sur la feuille numéro 0. Cette feuille (FORM) est créé automatiquement. Dans PANORAMIC_EDITOR, si vous lancez un RUN et que le programme ne comporte aucune ligne (source vide), cette feuille apparaîtra à l'exécution. Cet objet numéro 0 ne peut pas être détruit, mais peut être caché.

Comment créer un bouton et le positionner

Dans PANORAMIC_EDITOR, on tape:

tutoriel.bas 
button 1
top 1,50
left 1,100

puis on clique sur RUN (ou on tape sur F9)

 

Les résultats sont:

- un FORM est créée automatiquement (il a le numéro interne 0),

- un Bouton (de taille standard) est créé sur la forme (il a le numéro interne 1),

- Il est placé à 50 pixels du haut de la forme et à 100 pixels du bord gauche de la forme.
