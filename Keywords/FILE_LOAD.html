FILE_LOAD N,F

REMPLIT L'OBJET SYSTÈME NUMÉRO N AVEC LE CONTENU DU FICHIER F


  • Type: Commande
  • Paramètres: 2
  • Groupe: Objets Système


ACTION

La commande FILE_LOAD N,F remplit l'objet système désigné par son numéro N avec le contenu du fichier F.

L'objet système est du type : MEMO, MEMO_RICH, COMBO, LIST, PICTURE, SOUND, MOVIE, BUTTON_PICTURE, DLIST, SCENE2D, HVIEWER, IMAGE, SYNEDIT.


SYNTAXE : FILE_LOAD N,F

  • N = expression entière ou réelle, numéro de l'objet système. Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • F = expression chaîne de caractères, chemin du fichier chargé dans l'objet système.

UTILISATION

  • La commande FILE_LOAD est utilisée pour remplir un MEMO, COMBO, LIST, PICTURE, SOUND, MOVIE, MEMO_RICH, BUTTON_PICTURE, DLIST, SCENE2D, HVIEWER, IMAGE, SYNEDIT avec un fichier.
  • Dans ce cas, il n'est pas nécessaire d'effacer le contenu de l'objet système (CLEAR) avant de le remplir avec un fichier.
  • La commande FILE_LOAD est utilisée pour donner "une signification" à un PICTURE, un SOUND, un MOVIE, un IMAGE.
  • Dans le cas d'un PICTURE, le fichier chargé est immédiatement visualisé.
  • Dans le cas d'un SOUND, ou un MOVIE il faut ensuite utiliser PLAY quand le fichier est chargé.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : MEMO, MEMO_RICH, COMBO, LIST, PICTURE, SOUND, MOVIE, BUTTON_PICTURE, DLIST, SCENE2D, HVIEWER, IMAGE, SYNEDIT.
  • Si F n'est pas une expression correcte.

EXEMPLE

FILE_LOAD.bas 
' EXEMPLE 1 : remplissage d'un LIST
' créer un LIST
list 1
' le remplir avec le contenu d'un fichier
file_load 1,"liste des noms.txt"
' ---------------------------------- 
' EXEMPLE 2 : affichage d'une image
' créer un PICTURE
picture 1
' le remplir avec un fichier graphique
file_load 1,"Ma maison.bmp"
' ---------------------------------- 
' EXEMPLE 3 : charger un son et le jouer
' créer un Son
sound 1
' charger un fichier son
file_load 1,"crack.wav"
' jouer le son
play 1
