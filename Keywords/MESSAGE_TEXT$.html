MESSAGE_TEXT$

MESSAGE_TEXT$

CONTIENT LE TEXTE DE L'EDIT DE MESSAGE_INPUT()


  • Type : Variable système
  • Paramètre : 0
  • Groupe : Messages


ACTION

La variable système est liée à la fenêtre-message MESSAGE_INPUT(T1,T2,T3).

Elle contient :

- T3 quand l'utilisateur ferme la fenêtre-message en cliquant sur le bouton "CANCEL" ou sur l'icone de fermeture (croix rouge).

- le texte de l'EDIT quand l'utilisateur ferme la fenêtre en cliquant sur le bouton OK.


SYNTAXE : MESSAGE_TEXT$ dans une expression


UTILISATION

  • La variable système MESSAGE_TEXT$ est utilisée pour traiter un texte saisi par l'utilisateur.

ERREUR

  • Rien.

EXEMPLE

MESSAGE_TEXT$.bas 
' attendre une entrée de l'utilisateur et afficher le texte qu'il a saisi
if message_input("Donnée à entrer", "Indiquez votre age" , "20")=1
 print "L'age est "+message_text$
end_if
