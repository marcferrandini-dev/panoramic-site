FILE_DIALOG N,T

FILE_DIALOG N,T

DEFINIT LE NOM DE FICHIER T PROPOSÉ PAR L'OBJET SYSTÈME NUMÉRO N


  • Type : Commande
  • Paramètres : 2
  • Groupe : Objets Système


ACTION

La commande FILTER_DIALOG N,T propose le nom de fichier T pour l'objet N.

N est un objet du type OPEN_DIALOG, SAVE_DIALOG, OPEN_DIALOG_PIC, SAVE_DIALOG_PIC.


SYNTAXE : FILE_DIALOG N,F

  • N = expression entière ou réelle, numéro de l'objet système. Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • F = expression chaîne de caractères.

UTILISATION

  • La commande FILTER_DIALOG est utilisée pour proposer un nom de fichier dans les objets système de type OPEN_DIALOG, SAVE_DIALOG, OPEN_DIALOG_PIC, SAVE_DIALOG_PIC

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : OPEN_DIALOG, SAVE_DIALOG, OPEN_DIALOG_PIC, SAVE_DIALOG_PIC.
  • Si F n'est pas une expression string correcte.

EXEMPLE

FILE_DIALOG.bas 
dim f$
open_dialog 1
file_dialog 1,"MonFichier.txt"
caption 0,"Vérifier que le nom de fichier proposé est MonFichier.txt"
f$=file_name$(1)
