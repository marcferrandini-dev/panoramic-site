GRID_CLEAR N,R,C

GRID_CLEAR N,R,C

EFFACE LES CELLULES DU GRID NUMÉRO N DE LA LIGNE 1 À R ET DE LA COLONNE 1 À C


  • Type: Commande
  • Paramètres: 3
  • Groupe: Objets Système


ACTION

La commande GRID_CLEAR N,R,C efface les cellules du GRID numéro N de la ligne 1 à R et de la colonne 1 à C.


SYNTAXE : GRID_CLEAR N,R,C,F

  • N = expression entière ou réelle, numéro de l'objet système. Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • R = numéro de ligne (entier ou réel) de l'objet système GRID.
  • C = numéro de colonne (entier ou réel) de l'objet système GRID.
  • F = expression chaîne de caractères, chemin du fichier.

UTILISATION

  • La commande GRID_CLEAR est utilisée pour effacer partiellement le contenu GRID.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : GRID.
  • Si R ou C n'est pas une expression correcte.
  • Si R ou C est inférieur ou égal à 0.

EXEMPLE

GRID_CLEAR.bas 
' on crée un GRID
grid 1
' on le positionne
top 1,10:left 1,10
' on le dimensionne
width 1,350:height 1,150
' on le remplit avec des valeurs
grid_write 1,1,1,"Cellule 1,1"
grid_write 1,1,2,"Cellule 1,2"
grid_write 1,1,3,"Cellule 1,3"
grid_write 1,1,4,"Cellule 1,4"
grid_write 1,2,1,"Cellule 2,1"
grid_write 1,2,2,"Cellule 2,2"
grid_write 1,2,3,"Cellule 2,3"
grid_write 1,2,4,"Cellule 2,4"
grid_write 1,3,1,"Cellule 3,1"
grid_write 1,3,2,"Cellule 3,2"
grid_write 1,3,3,"Cellule 3,3"
grid_write 1,3,4,"Cellule 3,4"
' on attend 1 seconde
wait 1000
' on l'efface
grid_clear 1,3,4
