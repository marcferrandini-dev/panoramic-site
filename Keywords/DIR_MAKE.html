DIR_MAKE D

CRÉE LE RÉPERTOIRE D


  • Type: Commande
  • Paramètre: 1
  • Groupe: Répertoires


ACTION

La commande DIR_MAKE D crée le répertoire D. D est le nom absolu ou relatif du répertoire.

Si D est un nom relatif, D est créé comme sous-répertoire du répertoire courant.

Le nom absolu du répertoire est le nom complet, par rapport à la racine du système de fichier (ex: "c:\temp\files\" ou "c:\temp\files").

Le nom relatif est le nom du répertoire par rapport au répertoire courant (ex: "files").

Remarque 1: DIR_MAKE "c:\aaa\bbb" n'est valide que si c:\aaa existe déjà. Si a:\aaa n'existe pas, il y a une erreur.

Remarque 2: Si c:\aaa n'existe pas, pour créer c:\aaa\bbb il faut chaîner 2 actions:

DIR_MAKE "c:\aaa"

DIR_MAKE "c:\aaa\bbb"


SYNTAXE : DIR_MAKE D

  • D = nom absolu ou relatif du répertoire.

UTILISATION

  • La commande DIR_MAKE est utilisée pour créer un répertoire.

ERREUR

  • Si D n'est pas un nom correct de répertoire.

EXEMPLE

' créer le répertoire "abcd" dans le répertoire courant

dir_make "abcd"

' créer le répertoire "c:\aaaa"

dir_make "c:\aaaa"


EN RAPPORT

DIR_CHANGE

DIR_EXISTS()

DIR_CURRENT$
