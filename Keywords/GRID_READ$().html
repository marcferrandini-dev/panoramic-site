GRID_READ$(N,R,C)

RETOURNE LE CONTENU DE LA CELLULE (R,C) DU GRID NUMÉRO N


  • Type: Fonction
  • Paramètres: 3
  • Groupe: Objets Système


ACTION

La fonction GRID_READ$(N,R,C) retourne une chaîne de caractères qui est le contenu de la cellule définie par (R,C) dans le GRID numéro N. R est le numéro de ligne et C est le numéro de colonne.

Dans un GRID, les numéros de ligne et de colonne commencent à 1.

Remarque: le mot-clé GRID_READ$ se termine par '$' : cela veut dire que la valeur retournée est du type chaîne de caractères.


SYNTAXE : Resultat$=GRID_READ$(N,R,C)

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • R = numéro de ligne (entier ou réel)
  • C = numéro de colonne (entier ou réel)
  • Resultat$ est une chaîne de caractères

UTILISATION

  • La fonction GRID_READ$() est utilisée pour lire le contenu d'une cellule d'un GRID.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet numéro N n'existe pas.
  • Si le numéro N n'est pas le numéro d'un objet système : GRID.
  • Si R n'est pas une expression correcte.
  • Si C n'est pas une expression correcte.

EXEMPLE

' crée un GRID avec sa position et ses dimensions par défaut

grid 1

' écrit dans la cellule (2,3)

grid_write 1,2,3,"Bonjour"

' imprime le contenu de cette cellule

print grid_read$(1,2,3)
