PARENT(N)

RETOURNE LE NUMÉRO DU PARENT DE L'OBJET SYSTÈME NUMÉRO N


  • Type: Fonction
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La fonction PARENT(N) retourne le numéro du parent de l'objet système numéro N.


SYNTAXE : Resultat=PARENT(N)

  • N = numéro de l'objet système (entier ou réel).

UTILISATION

  • La fonction PARENT() est utilisée pour connaître le parent d'un objet système.

ERREUR

  • Si le numéro N n'est pas une expression correcte.

EXEMPLE

PARENT().bas 
' créer un BUTTON
button 1
' afficher le numéro de son parent comme caption
caption 1,parent(1)
