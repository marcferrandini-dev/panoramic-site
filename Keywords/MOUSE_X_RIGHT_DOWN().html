MOUSE_X_RIGHT_DOWN(N)

MOUSE_X_RIGHT_DOWN(N)

RETOURNE LA POSITION EN X DE LA SOURIS LORSQUE LE BOUTON DROIT EST ENFONCÉ SUR L'OBJET SYSTÈME NUMÉRO N


  • Type : Fonction
  • Paramètre : 1
  • Groupe : Souris


ACTION

La fonction MOUSE_X_RIGHT_DOWN(N) donne la position en X de la souris lorsque le bouton droit est enfoncé sur l'objet système numéro N.

La position 0 est la position du coin supérieur gauche de cet objet système.


SYNTAXE : Résultat=MOUSE_X_RIGHT_DOWN(N)

  • N = numéro d'objet système (entier ou réel). Doit être supérieur ou égal à 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La fonction MOUSE_X_RIGHT_DOWN() est utilisée pour connaître la position de la souris sur un objet système lorsqu'on enfonce le bouton droit, dans des jeux 2D et 3D.

ERREUR

  • Si le nombre N n'est pas une expression correcte.
  • Si le nombre N dépasse le nombre maximum permis d'objets systèmes.
  • Si le nombre N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N est du type : MAIN_MENU, SUB_MENU, SOUND, OPEN_DIALOG, SAVE_DIALOG, DLIST, TIMER, MAIN_MENU_POP,
  • OPEN_DIALOG_PIC, SAVE_DIALOG_PIC, SERIAL.
