FILE_ADD N,F

FILE_ADD N,F

AJOUTE LE CONTENU DU FICHIER F À L'OBJET SYSTÈME NUMÉRO N


  • Type : Commande
  • Paramètres : 2
  • Groupe : Objets Système


ACTION

La commande FILE_ADD N,F ajoute le contenu du fichier F à l'objet système désigné par son numéro N.

Le fichier F est dans le répertoire choisi.

Le fichier est ajouté après la dernière ligne (à la fin) de l'objet système.

L'objet système est du type : MEMO, MEMO_RICH, COMBO, LIST, DLIST.


SYNTAXE : FILE_ADD N,F

  • N = expression entière ou réelle, numéro de l'objet système. Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • F = expression chaîne de caractères, chemin du fichier ajouté à l'objet système.

UTILISATION

  • La commande FILE_ADD est utilisée pour ajouter un fichier au contenu d'un MEMO, MEMO_RICH, COMBO, LIST ou DLIST.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : MEMO, MEMO_RICH, COMBO, LIST, DLIST.
  • Si F n'est pas une expression correcte.

EXEMPLE

FILE_ADD.bas 
' créer un LIST
list 1
' le remplir avec le contenu d'un fichier
file_load 1,"liste des noms.txt"
' lui ajouter un autre fichier
file_add 1,"liste des noms2.txt"
