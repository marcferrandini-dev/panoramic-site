TIMER_ON N

TIMER_ON N

REND ACTIF L'OBJET SYSTÈME TIMER NUMÉRO N


  • Type: Commande
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La commande TIMER_ON N rend actif l'objet système TIMER désigné par son numéro N: le TIMER se déclenchera périodiquement.


SYNTAXE : TIMER_ON N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande TIMER_ON est utilisée pour rendre actif un TIMER.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : TIMER.

EXEMPLE

TIMER_ON.bas 
' après 5 secondes, affiche toutes les secondes un nombre de 1 à 10 puis s'arrête
label compte
dim i%
' crée un TIMER
timer 1
' le TIMER est inactivé
timer_off 1
on_timer 1,compte
' attendre 5 secondes
wait 5000
' le TIMER est activé
timer_on 1
end
compte:
i%=i%+1
print i%
if i%=10 then timer_off 1
return
