3D_MESH N

3D_MESH N

CRÉE UN OBJET MAILLÉ (OBJET 3D AU FORMAT 3DS) ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type : Commande
  • Paramètre : 1
  • Groupe : Objets 3D


ACTION

La commande 3D_MESH crée un objet maillé, qui est un objet 3D structuré dans le format 3DS et lui donne un numéro N.

Le numéro N est utilisé pour désigner cet objet maillé.

Le centre de l'objet maillé est placé en (0,0,0) : le centre du monde 3D (SCENE3D).

La couleur de l'objet maillé est grise à la création et peut être modifiée par la commande 3D_COLOR.

L'objet maillé peut être déplacé, tourné, déformé, coloré, texturé, supprimé, caché, visualisé... avec les commandes appropriées.

Remarque 1 : par défaut, l'objet maillé est créé dans le premier SCENE3D créé, mais un autre SCENE3D peut être utilisé. Pour cela, créer un nouveau SCENE3D et lui envoyer les commandes par 3D_TARGET_IS avant la création de l'objet maillé.

Remarque 2 : après la création d'un objet maillé, un fichier (dans le format 3DS) peut être chargé dans l'objet maillé par la commande 3D_LOAD_OBJECT. Il peut être alors normalement traité comme n'importe quel objet 3D.


SYNTAXE : 3D_MESH N

  • N = numéro d'objet 3D (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets 3D.

UTILISATION

  • La commande 3D_MESH est utilisée pour créer un objet "3DS" dans un SCENE3D.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets 3D.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le numéro N est déjà utilisé pour un autre objet 3D.
  • Si aucun SCENE3D n'est créé.

EXEMPLE

3D_MESH.bas 
' crée un monde 3D
scene3d 1
' crée un objet maillé numéro 1
3d_mesh 1
' charge un fichier dans l'objet maillé
3d_load_object 1,"maison.3ds"
