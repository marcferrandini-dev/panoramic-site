EXIT_SUB

EXIT_SUB

TERMINE UN SOUS-PROGRAMME SANS EXECUTER END_SUB


  • Type : Commande
  • Paramètre : 0
  • Groupe : Structures


ACTION

La commande EXIT_SUB termine un sous-programme sans exécuter END_SUB


SYNTAXE : EXIT_SUB


UTILISATION

  • La commande EXIT_SUB est utilisée pour terminer un sous-programme sans exécuter END_SUB.

ERREUR

  • Rien.

EXEMPLE

EXIT_SUB.bas 
dim i%
for i%=1 to 10
 imprime(i%)
next i%
end
sub imprime(j%)
' sort si j% vaut 5,6 ou 7
if (j%=5) or (j%=6) or (j%=7) then exit_sub
print j%
end_sub

EN RAPPORT

SUB

END_SUB
