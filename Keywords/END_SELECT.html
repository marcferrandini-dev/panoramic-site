END_SELECT

END_SELECT

TERMINE UNE STRUCTURE INITIÉE PAR "SELECT"


  • Type : Directive
  • Paramètre : 0
  • Groupe : Structures


ACTION

La déclaration est une partie de la structure SELECT/CASE/END_SELECT et est utilisée pour terminer La structure :

- Si aucun CASE ne correspond à la valeur évaluée par SELECT, les instructions qui suivent END_SELECT sont exécutées.

- Lorsque toutes les instructions suivant un CASE ont été exécutés, les instructions qui suivent END_SELECT sont exécutées.


SYNTAXE : END_SELECT


UTILISATION

  • END_SELECT est utilisé, en association avec SELECT et CASE, pour terminer la structure initialisée par SELECT.

ERREUR

  • Rien.

EXEMPLE

END_SELECT.bas 
dim v
v=5
select v
case 1:print "V vaut 1"
case 5:print "V vaut 5"
case 8:print "V vaut 8"
end_select

EN RAPPORT

CASE
