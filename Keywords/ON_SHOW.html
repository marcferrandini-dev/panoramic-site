ON_SHOW N,L

ON_SHOW N,L

EXÉCUTE LE PROGRAMME À PARTIR DU LABEL L QUAND L'OBJET SYSTÈME NUMÉRO N (FORM ou TAB) EST VISUALISÉ


  • Type: Commande
  • Paramètres: 2
  • Groupe: Evénements


ACTION

La commande ON_SHOW N,L assigne un label (qui doit être défini dans le programme) à partir duquel le programme s'exécute quand l'utilisateur visualise l'objet système désigné par le numéro N.

L'objet système doit être de type FORM ou TAB.


SYNTAXE : ON_SHOW N,L

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • L = label.

UTILISATION

  • La commande ON_SHOW est utilisée pour associer un événement (show) arrivant à un objet système, à un emplacement de programme (défini par le label L).
  • Quand l'événement arrive, le programme marqué par le label est exécuté.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : FORM, TAB.
  • Si le label L n'existe pas.
  • Si L n'est pas un nom de label correct.

EXEMPLE

ON_SHOW.bas 
label show,click
dim k%
k%=0
button 1:width 1,200:top 1,20:left 1,20:caption 1, "Cliquez pour cacher ce FORM"
on_show 0, show
on_click 1, click
end
show:
k%=k%+1
caption 0, "nombre de SHOWs: "+str$(k%)
return
click:
hide 0
wait 1000
show 0
return
