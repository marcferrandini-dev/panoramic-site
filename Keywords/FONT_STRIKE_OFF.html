FONT_STRIKE_OFF N

FONT_STRIKE_OFF N

RETIRE LE STYLE "RAYÉ" AU STYLE DE L'OBJET SYSTÈME NUMÉRO N


  • Type: Commande
  • Paramètre: 1
  • Groupe: Police


ACTION

La commande FONT_STRIKE_OFF N retire le style "rayé" au style des caractères de l'objet système désigné par son numéro N.

L'objet système est du type : BUTTON, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, SPIN, GRID, CONTAINER, MEMO_RICH, BUTTON_PICTURE, SCENE2D, PANEL, GRID_DRAW, CONTAINER_OPTION, TAB, SYNEDIT, CHART.


SYNTAXE : FONT_STRIKE_OFF N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande FONT_STRIKE_OFF est utilisée pour retirer le "rayé" du texte visualisé par un objet système.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si le numéro N n'est pas un objet système du type : BUTTON, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, SPIN, GRID, CONTAINER, MEMO_RICH, BUTTON_PICTURE, SCENE2D, PANEL, GRID_DRAW, CONTAINER_OPTION, TAB, SYNEDIT, CHART.

EXEMPLE

FONT_STRIKE_OFF.bas 
' créer un MEMO
memo 1
' le remplir avec une ligne
item_add 1,"Salut!"
' mettre la ligne en rayé
font_strike 1
wait 1000:' attendre 1 seconde
' retirer le rayé
font_strike_off 1
