COMMAND_TARGET_IS N

COMMAND_TARGET_IS N

DÉSIGNE L'OBJET SYSTÈME NUMÉRO N COMME RÉCEPTEUR DE COMMANDES


  • Type: Commande
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La commande COMMAND_TARGET_IS N désigne l'objet système numéro N qui recevra toutes les prochaines commandes. Cet objet système doit être un récepteur d'objets (FORM, CONTAINER, PANEL, TAB) et il devient l'objet "cible des commandes".

Par défaut, l'objet système "cible des commandes" est : FORM numéro 0.


SYNTAXE : COMMAND_TARGET_IS N

  • N = numéro de l'objet système (entier ou réel). Doit être supérieur à 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande COMMAND_TARGET_IS est utilisée pour créer des objets systèmes sur un récepteur d'objets (FORM, CONTAINER, PANEL, TAB).

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si le numéro N n'est pas le numéro d'un FORM, CONTAINER, PANEL, TAB.

EXEMPLE

COMMAND_TARGET_IS.bas 
' créer un FORM
form 1
' désigner ce FORM comme la cible des commandes
command_target_is 1
' créer un BUTTON sur ce FORM
button 2
caption 2,"Bouton sur Form1"
