DLL_ON D

DLL_ON D

CHARGE LA DLL D EN MÉMOIRE


  • Type : Commande
  • Paramètre : 1
  • Groupe : DLL


ACTION

La commande DLL_ON D charge en mémoire la DLL (Librairie de liens dynamiques) dont le nom est D. D est le nom absolu ou relatif du fichier DLL.

Le nom absolu du fichier est le nom complet, par rapport à la racine du système de fichier (ex : "c:\temp\mydll.dll").

Le nom relatif est le nom du fichier par rapport au répertoire courant (ex : "mydll.dll" ou "/file.dll" ou "\file.dll").

Pour les fichiers DLL, le nom relatif désigne soit le répertoire courant, soit le répertoire spécifique aux DLL : Windows/System32


SYNTAXE : DLL_ON D

  • D = chaîne de caractères, nom absolu ou relatif du fichier.

UTILISATION

  • La commande DLL_ON est utilisée pour charger une DLL en mémoire, afin de pouvoir appeler ses fonctions.

ERREUR

  • Si le fichier D n'existe pas.
  • Si D n'est pas un nom correct de fichier.

EXEMPLE

DLL_ON.bas 
dim v,r
' DLL chargée en mémoire
dll_on "ma_dll.dll"
' appel d'une fonction de la DLL avec 2 paramètres
v=23
r=dll_call2("func", 19, v)
' affichage du résultat
print v
' libération de la mémoire
dll_off
