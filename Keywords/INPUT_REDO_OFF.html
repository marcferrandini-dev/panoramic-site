INPUT_REDO_OFF

INPUT_REDO_OFF

NE RÉ-EXECUTE PAS LA COMMANDE INPUT SI AUCUNE VALEUR LUE


  • Type : Commande
  • Paramètre : 0
  • Groupe : Système


ACTION

Lors de l'exécution d'une commande INPUT, si aucune valeur n'est tapée (cas où seule la touche RETURN est tapée lors de la commande INPUT), il n'y a pas de nouvelle demande d'une entrée et la variable de la commande INPUT contiendra 0 si c'est une variable numérique et la chaine vide ("") si c'est une variable string.

La commande INPUT_REDO_OFF est active uniquement si le moyen d'entrée est le clavier.

Remarque : ne pas ré-exécuter la commande INPUT est le comportement par défaut de la commande INPUT.


SYNTAXE : INPUT_REDO_OFF


UTILISATION

  • La commande INPUT_REDO_OFF est utilisée pour entrer une valeur nulle ou une chaine vide dans une variable par une commande INPUT.

ERREUR

  • Rien.
