OFF_DOUBLE_CLICK N

OFF_DOUBLE_CLICK N

IGNORE L'ÉVÉNEMENT "DOUBLE CLIC" QUAND L'OBJET SYSTÈME NUMÉRO N EST DOUBLE-CLIQUÉ


  • Type : Commande
  • Paramètre : 1
  • Groupe : Evénements


ACTION

La commande OFF_DOUBLE_CLICK N ignore l'événement "double clic" quand l'utilisateur double-clique sur l'objet système désigné par le numéro N.

Remarque 1 : l'objet système doit être de l'un des types suivants : SCENE3D, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, OPTION, SPIN, GRID, CONTAINER.

Remarque 2 : le sous-programme de traitement d'événement est défini par la commande ON_DOUBLE_CLICK N,L qui assigne le label L comme point de départ du sous-programme de traitement d'événement.


SYNTAXE : OFF_DOUBLE_CLICK N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand ou égal à 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande OFF_DOUBLE_CLICK est utilisée pour ne plus associer l'événement "DOUBLE CLIC" arrivant à un objet système, à un emplacement de programme (défini par le label L).
  • Quand l'événement arrive, le programme marqué par le label n'est plus exécuté.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : SCENE3D, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, OPTION, SPIN, GRID, CONTAINER.

EXEMPLE

OFF_DOUBLE_CLICK.bas 
label col
dim c%
c%=3
edit 1
top 1,60
width 1,200
text 1,"double-cliquer sur moi "+str$(c%)+" fois"
on_double_click 1, col
end
col:
text 1,"double-cliqué"
wait 250
c%=C%-1
text 1,"double-cliquer sur moi "+str$(c%)+" fois"
if c%=0
 off_double_click 1
 text 1,"le double-clic est inactif"
end_if
return
