INPUT_MARK_ON

INPUT_MARK_ON

AFFICHE UN POINT D'INTERROGATION LORS D'UNE COMMANDE INPUT


  • Type : Commande
  • Paramètre : 0
  • Groupe : Système


ACTION

Lors de l'exécution d'une commande INPUT, un point d'interrogation est affiché sur l'objet système "récepteur des impressions".

Par défaut, le "récepteur des impressions" est FORM0, mais un objet système devient "récepteur des impressions" par la commande PRINT_TARGET_IS.


SYNTAXE : INPUT_MARK_ON


UTILISATION

  • La commande INPUT_MARK_ON est utilisée pour prévenir l'opérateur qu'une commande INPUT est en train d'être exécutée.

ERREUR

  • Rien.
