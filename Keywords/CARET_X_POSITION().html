CARET_X_POSITION(N)

RETOURNE LA POSITION EN COLONNE DU CURSEUR DE L'OBJET SYSTÈME NUMÉRO N


  • Type: Fonction
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La fonction CARET_X_POSITION(N) retourne la position du curseur de l'objet système de numéro N, exprimée en nombre de caractères. Quand le caret est à l'extrème gauche de la ligne, la valeur 1 est retournée.

L'objet système est du type MEMO, MEMO_RICH, SYNEDIT.


SYNTAXE : Resultat=CARET_X_POSITION(N)

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La fonction CARET_X_POSITION() est utilisée pour connaître la position du curseur sur une ligne, pour un objet manipulant du texte.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet numéro N n'est pas du type : MEMO, MEMO_RICH, SYNEDIT.

EXEMPLE

' créer un EDIT

edit 1

' visualiser un texte

text 1,"Hello"

' mettre le curseur entre "e" et "l"
