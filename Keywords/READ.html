READ V

READ V

STOCKE DANS LA VARIABLE V LA VALEUR TROUVÉE DANS UNE DÉCLARATION "DATA"


  • Type : Commande
  • Paramètres : n
  • Groupe : Référence


ACTION

La commande READ stocke dans la variable V la valeur trouvée dans une ligne DATA. Chaque fois qu'une valeur est lue, la donnée suivante en déclaration DATA est prête à être lue par la prochaine commande READ.


SYNTAXE : READ V

  • V = nom de variable (simple ou tableau)

UTILISATION

  • La commande READ est utilisée pour stocker dans une variable la valeur trouvée à l'intérieur du source du programme.

ERREUR

  • Si aucune valeur n'est disponible dans les déclarations DATA (toutes les données ont été lues)
  • S'il n'y a aucune déclaration de DATA

EXEMPLE

READ.bas 
dim a,b,c,d$
data 1,2,3,"Salut"
read a:print a
read b:read c:print b:print c
read d$:print d$

EN RAPPORT

DATA

RESTORE
