3D_COLLISION_AS_CUBE N

3D_COLLISION_AS_CUBE N

POUR LES COLLISIONS, L'OBJET 3D NUMÉRO N SE COMPORTE COMME SON CUBE ENGLOBANT


  • Type: Commande
  • Paramètre: 1
  • Groupe: Objets 3D


ACTION

La commande 3D_COLLISION_AS_CUBE N remplace dans les collisions, l'objet 3D désigné par son numéro N par un cube qui l'englobe et qui est aligné sur ses axes.


SYNTAXE : 3D_COLLISION_AS_CUBE N

  • N = numéro d'objet 3D (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets 3D.

UTILISATION

  • La commande est utilisée pour qu'un objet 3D se comporte comme un cube dans les collisions.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets 3D.
  • Si le numéro N est inférieur ou égal à 0.
  • Si l'objet 3D numéro N n'existe pas.

EXEMPLE

3D_COLLISION_AS_CUBE.bas 
' créer un monde 3D
scene3d 1
' créer un mesh
3d_mesh 1
' charger un fichier
3d_load_object 1,"mesh.3ds"
' faire comme si c'est un cube
3d_collision_as_cube
