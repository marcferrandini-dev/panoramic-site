ON_DOUBLE_CLICK N,L

ON_DOUBLE_CLICK N,L

EXÉCUTE LE PROGRAMME À PARTIR DU LABEL L QUAND L'OBJET SYSTÈME NUMÉRO N EST DOUBLE-CLIQUÉ


  • Type : Commande
  • Paramètres : 2
  • Groupe : Evénements


ACTION

La commande ON_DOUBLE_CLICK N,L assigne un label (qui doit être défini dans le programme) à partir duquel le programme s'exécutera chaque fois que l'utilisateur double-clique sur l'objet système désigné par le numéro N.

L'objet système doit être de l'un des types suivants : SCENE3D, EDIT, MEMO, MEMO_RICH, COMBO, ALPHA, FORM, LIST, PICTURE, OPTION, SPIN, GRID, CONTAINER.


SYNTAXE : ON_DOUBLE_CLICK N,L

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand ou égal à 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • L = label.

UTILISATION

  • La commande ON_DOUBLE_CLICK est utilisée pour associer un événement (DOUBLE CLIC) arrivant à un objet système, à un emplacement de programme (défini par le label L).
  • Quand l'événement arrive, le programme marqué par le label est exécuté.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : SCENE3D, EDIT, MEMO, MEMO_RICH, COMBO, ALPHA, FORM, LIST, PICTURE, OPTION, SPIN, GRID, CONTAINER.
  • Si le label L n'existe pas.
  • Si L n'est pas un nom de label correct.

EXEMPLE

ON_DOUBLE_CLICK.bas 
label col
dim c%
c%=3
edit 1
top 1,60
width 1,200
text 1,"double-cliquer sur moi "+str$(c%)+" fois"
on_double_click 1, col
end
col:
text 1,"double-cliqué"
wait 250
c%=C%-1
text 1,"double-cliquer sur moi "+str$(c%)+" fois"
if c%=0
 off_double_click 1
 text 1,"le double-clic est inactif"
end_if
return
