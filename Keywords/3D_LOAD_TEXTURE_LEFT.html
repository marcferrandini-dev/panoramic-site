3D_LOAD_TEXTURE_LEFT N,F

3D_LOAD_TEXTURE_LEFT N,F

APPLIQUE SUR LA FACE GAUCHE DE L'OBJET 3D_SKYBOX NUMÉRO N LA TEXTURE DANS LE FICHIER F


  • Type : Commande
  • Paramètres : 2
  • Groupe : Objets 3D


ACTION

La commande 3D_LOAD_TEXTURE_LEFT N,F assigne une texture à la face gauche d'un objet 3D_SKYBOX existant.

La texture est dans le fichier F.

Le fichier doit être dans le format BMP (Bitmap).


SYNTAXE : 3D_LOAD_TEXTURE_LEFT N,F

  • N = numéro d'objet 3D (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets 3D.
  • F = nom (absolu ou relatif) du fichier contenant la texture

UTILISATION

  • La commande est utilisée pour donner une texture gauche à un 3D_SKYBOX.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets 3D.
  • Si le numéro N est inférieur ou égal à 0.
  • Si l'objet 3D numéro N n'existe pas.
  • Si le numéro N ne correspond à un 3D_SKYBOX.
  • Si F n'est pas une expression string correcte.
  • Si le fichier F n'existe pas.

EXEMPLE

3D_LOAD_TEXTURE_LEFT.bas 
' créer un monde 3D
scene3d 1
' créer un 3D_SKYBOX
3d_skybox 1
' lui donner une texture basse
3d_load_texture_bottom 1,"bottom.bmp"
' lui donner une texture haute
3d_load_texture_top 1,"top.bmp"
' lui donner une texture avant
3d_load_texture_front 1,"front.bmp"
' lui donner une texture arrière
3d_load_texture_back 1,"back.bmp"
' lui donner une texture droite
3d_load_texture_right 1,"right.bmp"
' lui donner une texture gauche
3d_load_texture_left 1,"left.bmp"
