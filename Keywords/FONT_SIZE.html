FONT_SIZE N,S

FONT_SIZE N,S

DÉFINIT LA TAILLE DES CARACTÈRES VISUALISÉS PAR L'OBJET SYSTÈME NUMÉRO N


  • Type : Commande
  • Paramètres : 2
  • Groupe : Police


ACTION

La commande FONT_SIZE N,S définit la taille S des caractères visualisés par l'objet système numéro N.

L'objet système est du type : BUTTON, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, SPIN, GRID, CONTAINER, MEMO_RICH, BUTTON_PICTURE, SCENE2D, PANEL, GRID_DRAW, CONTAINER_OPTION, TAB, SYNEDIT, CHART.


SYNTAXE : FONT_SIZE N,S

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • S = taille des caractères (entier ou réel)

UTILISATION

  • La commande FONT_SIZE est utilisée pour définir la taille du texte visualisé par un objet système.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si le numéro N n'est pas un objet système de type : BUTTON, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, SPIN, GRID, CONTAINER, MEMO_RICH, BUTTON_PICTURE, SCENE2D, PANEL, GRID_DRAW, CONTAINER_OPTION, TAB, SYNEDIT, CHART.
  • Si la taille S est inférieur ou égale à 0.
  • Si la taille S n'est pas une expression correcte.

EXEMPLE

FONT_SIZE.bas 
' créer un MEMO
memo 1
' le remplir avec une ligne
item_add 1,"Salut!"
' attendre 1 seconde
wait 1000
' mettre la ligne en taille 20
font_size 1,20
