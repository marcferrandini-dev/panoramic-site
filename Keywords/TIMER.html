TIMER N

CRÉE UN OBJET SYSTÈME TIMER ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type: Commande
  • Paramètre: 1
  • Groupe: Création Objets Système


ACTION

La commande crée un objet système TIMER et lui donne un numéro N. Le numéro N sera utilisé pour désigner ce TIMER.

Le TIMER créé peut alors être utilisé par les commandes appropriées (ON_TIMER, TIMER_INTERVAL, TIMER_ON, TIMER_OFF), mais n'est pas visible.

Un TIMER peut générer l'événement : ON_TIMER.

Remarque 1: le TIMER est créé actif et sa période vaut 1000 millisecondes.

Remarque 2: un TIMER peut être désactivé par TIMER_OFF et réactivé par TIMER_ON.

Remarque 3: sa période (en millisecondes) est modifiée par TIMER_INTERVAL.


SYNTAXE : TIMER N

  • N = numéro d'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • Un TIMER est utilisé pour exécuter périodiquement un sous-programme (ON_TIMER).

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le numéro N est déjà utilisé pour un numéro d'objet système.

EXEMPLE

' chaque seconde affiche un nombre de 1 à 10 puis s'arrête

label compte

dim i%

' crée un TIMER

timer 1

on_timer 1,compte

end

compte:

i%=i%+1

print i%

if i%=10 then timer_off 1

return
