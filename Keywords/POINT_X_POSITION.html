POINT_X_POSITION X

POINT_X_POSITION X

MODIFIE LA COORDONNÉE EN X DU POINT VISÉ PAR LA CAMÉRA 3D


  • Type : Commande
  • Paramètre : 1
  • Groupe : Objets 3D


ACTION

La commande POINT_X_POSITION X modifie la coordonnée X du point visé par la caméra 3D appartenant au SCENE3D cible (premier SCENE3D créé ou SCENE3D sélectionné par 3D_TARGET_IS N) et place le point visé à la position (X,Y,Z), les coordonnées Y et Z du point étant inchangées.

Par défaut, la caméra 3D est placée à la position (0,0,5), vise le point (0,0,0) et le SCENE3D cible est le premier SCENE3D créé.


SYNTAXE : POINT_X_POSITION X

  • X = nouvelle position en X. X peut être un nombre entier ou réel.

UTILISATION

  • La commande POINT_X_POSITION est utilisée pour déplacer en X le point visé par la caméra 3D.

ERREUR

  • Si la position X n'est pas une expression correcte
  • Si aucun SCENE3D n'est créé

EXEMPLE

POINT_X_POSITION.bas 
' créer un monde 3D
scene3d 1
' créer un objet 3D (une théière)
3d_teapot 1
' positionner en X le point visé par la caméra 3D
point_x_position 0.5
