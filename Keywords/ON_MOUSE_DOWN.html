ON_MOUSE_DOWN N,L

EXÉCUTE LE PROGRAMME À PARTIR DU LABEL L QUAND L'UTILISATEUR PRESSE UNE TOUCHE DE LA SOURIS AU-DESSUS DE L'OBJET SYSTÈME NUMÉRO N


  • Type: Commande
  • Paramètres: 2
  • Groupe: Evénements


ACTION

La commande ON_MOUSE_DOWN N,L assigne un label (qui doit être défini dans le programme) à partir duquel le programme s'exécutera chaque fois que l'utilisateur presse une touche de la souris et que la souris est au-dessus de l'objet système désigné par le numéro N.

L'objet système doit être de l'un des types suivants: SCENE3D, BUTTON , EDIT, MEMO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, PROGRESS_BAR, SPIN, GRID, CONTAINER, SCENE2D, PANEL, CONTAINER_TAB, TAB.


SYNTAXE : ON_MOUSE_DOWN N,L

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • L = label.

UTILISATION

  • La commande ON_MOUSE_DOWN est utilisée pour associer un événement (MOUSE_DOWN) arrivant à un objet système, à un emplacement de programme (défini par le label L).
  • Quand l'événement arrive, le programme marqué par le label est exécuté.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : SCENE3D, BUTTON , EDIT, MEMO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, PROGRESS_BAR, SPIN, GRID, CONTAINER, SCENE2D, PANEL, CONTAINER_TAB, TAB.
  • Si le label L n'existe pas.
  • Si L n'est pas un nom de label correct.

EXEMPLE

label down, up

button 1

left 1,300

width 1,200

on_mouse_up 1, down

on_mouse_up 1, up

caption 0,"Appuyez et relâchez une touche de la souris sur le Button"

end

down:

caption 0,"DOWN sur BUTTON"

pause 1000:caption 0,""

off_mouse_down 1

return

up:

caption 0,"UP sur BUTTON"

pause 1000:caption 0,""

off_mouse_up 1

return
