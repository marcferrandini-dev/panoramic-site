ON_CHANGE N,L

EXÉCUTE LE PROGRAMME À PARTIR DU LABEL L QUAND L'OBJET SYSTÈME NUMÉRO N A "CHANGÉ"


  • Type: Commande
  • Paramètres: 2
  • Groupe: Evénements


ACTION

La commande ON_CHANGE N,L assigne un label (qui doit être défini dans le programme) à partir duquel le programme s'exécutera chaque fois que l'utilisateur change quelque chose dans l'objet système désigné par le numéro N.

L'objet système doit être de l'un des types suivants: MEMO, EDIT, COMBO, TRACK_BAR, SCROLL_BAR.

Remarque : pour un COMBO, l'événement correspond à un changement sur sa boite d'édition: un COMBO est comme un EDIT.


SYNTAXE : ON_CHANGE N,L

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • L = label.

UTILISATION

  • La commande ON_CHANGE est utilisée pour associer un événement (CHANGE) arrivant à un objet système, à un emplacement de programme (défini par le label L).
  • Quand l'événement arrive, le programme marqué par le label est exécuté.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : MEMO, EDIT, COMBO, TRACK_BAR, SCROLL_BAR.
  • Si le label L n'existe pas.
  • Si L n'est pas un nom de label correct.

EXEMPLE

ON_CHANGE.bas 
' déclarer un label
label changed
' un MEMO est créé
memo 1
' chaque fois que le MEMO change, exécuter à partir du label "changed"
on_change 1,changed
end : ' le programme principal est fini
changed:
beep : ' traitement d'événement = signal sonore
return
