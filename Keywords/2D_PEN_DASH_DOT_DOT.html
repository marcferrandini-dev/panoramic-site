2D_PEN_DASH_DOT_DOT

2D_PEN_DASH_DOT_DOT

DÉFINIT LE STYLE DU TRACÉ : SERIE DE TRAIT ET DEUX POINTS


  • Type : Commande
  • Paramètre : 0
  • Groupe : Dessin


ACTION

La commande 2D_PEN_DASH_DOT_DOT définit le style du tracé pour tous les nouveaux dessins avec des séries de trait et deux points.

Par défaut, le tracé est plein. La commande 2D_PEN_SOLID revient au tracé plein.

Remarque : cette commande n'est active que si la largeur du tracé est 1 (2D_PEN_WIDTH).


SYNTAXE : 2D_PEN_DASH_DOT_DOT


UTILISATION

  • La commande 2D_PEN_DASH_DOT_DOT est utilisée pour définir un style pour les prochains tracés.

ERREUR

  • Rien.

EXEMPLE

2D_PEN_DASH_DOT_DOT.bas 
' trace un rectangle
' la ligne est constituée de séries de trait et deux points
2d_pen_dash_dot_dot
2d_rectangle 10,10,400,350
