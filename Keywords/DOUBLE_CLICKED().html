DOUBLE_CLICKED(N)

DOUBLE_CLICKED(N)

RETOURNE 1 SI L'OBJET SYSTÈME NUMÉRO N A ÉTÉ DOUBLE-CLIQUÉ, 0 SINON


  • Type : Fonction
  • Paramètre : 1
  • Groupe : Objets Système


ACTION

La fonction DOUBLE_CLICKED(N) retourne 1 si l'objet système désigné par son numéro N a été double-cliqué et 0 si l'objet système n'a pas été double-cliqué.

L'objet système N est du type : SCENE3D, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, OPTION, SPIN, GRID, CONTAINER.


SYNTAXE : Resultat=DOUBLE_CLICKED(N)

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand ou égal à 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La fonction DOUBLE_CLICKED() est utilisée pour savoir si l'objet système est double-cliqué par l'utilisateur.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : SCENE3D, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, OPTION, SPIN, GRID, CONTAINER.

EXEMPLE

DOUBLE_CLICKED().bas 
label loop
edit 1:top 1,100
caption 0,"test de DOUBLE_CLICKED sur un EDIT"
print "double-cliquer sur l'EDIT"
loop:
if double_clicked(1)<>1
 wait 100
 goto loop
end_if
caption 0,"OK ---> DOUBLE_CLICKED sur l' EDIT"
print "L'EDIT a reçu un double-click"
