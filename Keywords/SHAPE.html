SHAPE N

SHAPE N

CRÉE UN OBJET SYSTÈME SHAPE ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type : Commande
  • Paramètre : 1
  • Groupe : Création Objets Système


ACTION

La commande SHAPE N crée un SHAPE et lui donne un numéro N. Le numéro N sera utilisé pour désigner ce SHAPE.

Le SHAPE créé peut alors être utilisé par les commandes appropriées.

Le SHAPE est créé à la position (0,0) : c'est à dire TOP = 0 pixel et LEFT = 0 pixel, avec les dimensions WIDTH = 65 pixels et HEIGHT = 65 pixels.

Un SHAPE est un objet dont on peut modifier la forme par les commandes SHAPE_RECTANGLE_ROUNDED, SHAPE_SQUARE_ROUNDED, SHAPE_RECTANGLE, SHAPE_ELLIPSE, SHAPE_SQUARE, SHAPE_CIRCLE.

Par défaut, un SHAPE créé est un cercle.

Un SHAPE peut générer les événements : ON_MOUSE_MOVE, ON_MOUSE_UP, ON_MOUSE_DOWN.

Remarque : par défaut, le SHAPE est créé sur le FORM numéro 0, mais un autre FORM peut être utilisé. Pour cela, créer un FORM par FORM N et lui envoyer les commandes par COMMAND_TARGET_IS N avant la création du SHAPE.


SYNTAXE : SHAPE N

  • N = numéro d'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • Un SHAPE est utilisé comme un objet dont on peut changer la forme.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le numéro N est déjà utilisé pour un numéro d'objet système.

EXEMPLE

SHAPE.bas 
shape 1
width 1,300
height 1,100
caption 0,"CIRCLE"
pause 2000
shape_square 1
caption 0,"SQUARE"
pause 2000
shape_square_rounded 1
caption 0,"SQUARE_ROUNDED"
pause 2000
shape_rectangle 1
caption 0,"RECTANGLE"
pause 2000
shape_rectangle_rounded 1
caption 0,"RECTANGLE_ROUNDED"
pause 2000
shape_ellipse 1
caption 0,"ELLIPSE"
pause 2000
shape_circle 1
caption 0,"CIRCLE"
