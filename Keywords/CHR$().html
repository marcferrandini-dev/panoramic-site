CHR$(N)

RETOURNE LE CARACTÈRE CORRESPONDANT AU CODE ASCII N


  • Type: Fonction
  • Paramètre: 1
  • Groupe: Chaines de caractères


ACTION

La fonction CHR$(N) retourne la chaîne de caractères correspondante au code ASCII de l'expression N.

N doit être compris entre 0 et 255.

Remarque 1: CHR$(N) exécute la fonction inverse de ASC(S).

Remarque 2: le mot-clé CHR$ se termine par '$' : cela veut dire que la valeur retournée est du type chaîne de caractères.


SYNTAXE : Resultat$=CHR$(N)

  • N = expression contenant un code ASCII de 0 à 255.
  • Resultat$ est une chaîne de caractères.

UTILISATION

  • La fonction CHR$() est utilisée pour connaître le caractère correspondant à un code ASCII.

ERREUR

  • Si N n'est pas une expression correcte.
  • Si N est inférieur à 0 ou supérieur à 255.

EXEMPLE

CHR$().bas 
print chr$(65)
print "A"

EN RAPPORT
