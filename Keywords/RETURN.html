RETURN

RETURN

TERMINE UN SOUS-PROGRAMME


  • Type : Commande
  • Paramètre : 0
  • Groupe : Référence


ACTION

La commande provoque le retour de l'exécution d'un sous-programme à la commande qui suit immédiatement le GOSUB appelant dans le programme principal, ou remet le programme en attente d'événement si le sous-programme était un traitement d'événement (Pas appelé par GOSUB dans ce cas).

La commande est utilisée pour terminer un sous-programme.

Un sous-programme est un groupe de commandes qui commence par un LABEL et se termine avec RETURN et qui peut être traité un certain nombre de fois.


SYNTAXE : RETURN


UTILISATION

  • La commande RETURN est utilisée pour terminer un sous-programme (appelé par le programme principal ou par l'arrivée d'un événement)

ERREUR

  • Rien.

EXEMPLE

RETURN.bas 
dim a,b
label addition
a=1:b=1
gosub addition
end
addition:
print a+b
return

EN RAPPORT

GOSUB
