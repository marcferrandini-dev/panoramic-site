FORM N

FORM N

CRÉE UN OBJET SYSTÈME FORM ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type : Commande
  • Paramètre : 1
  • Groupe : Création Objets Système


ACTION

La commande FORM N crée un objet système FORM et lui donne un numéro N. Le numéro N sera utilisé pour désigner ce FORM.

Le FORM créé peut alors être utilisé par les commandes appropriées.

Le FORM est créé à la position (0,0) : c'est à dire TOP = 0 pixel et LEFT = 0 pixel, avec les dimensions WIDTH = 320 pixels et HEIGHT = 240 pixels.

Un FORM montre une fenêtre avec des composants.

Un FORM peut générer les événements : ON_CLICK, ON_DOUBLE_CLICK, ON_KEY_UP, ON_KEY_DOWN.

Remarque : par défaut, le FORM numéro 0 est créé et visualisé au RUN.


SYNTAXE : FORM N

  • N = numéro d'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • Un FORM est utilisée pour montrer une fenêtre avec des composants.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le numéro N est déjà utilisé pour un numéro d'objet système.

EXEMPLE

FORM.bas 
' crée un FORM avec la position et les dimensions par défaut 
form 1
' visualiser un texte expliquant son rôle (son numéro est utilisé comme référence)
caption 1,"Table Principale"
