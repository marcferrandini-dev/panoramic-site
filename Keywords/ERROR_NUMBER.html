ERROR_NUMBER

RETOURNE LE NUMÉRO DE L'ERREUR


  • Type: Variable système
  • Paramètre: 0
  • Groupe: Référence


ACTION

La variable système ERROR_NUMBER retourne le numéro de l'erreur, dans le cas où une erreur s'est produite et que la commande ON_ERROR_GOTO a été exécutée.

Si aucune commande ON_ERROR_GOTO a été exécutée ou si aucune erreur ne s'est produite, sa valeur est 0.

Si une erreur s'est produite et que la commande ON_ERROR_GOTO a été exécutée, ERROR_NUMBER contient le code de l'erreur rencontrée.


SYNTAXE : ERROR_NUMBER dans une expression


UTILISATION

  • La variable système ERROR_NUMBER est utilisée pour connaître le code d'une erreur rencontrée.

ERREUR

  • Rien.

EXEMPLE

label err

on_error_goto err

top 0, 3+:' erreur ici

print "jamais imprimé"

err:

print "erreur"

print error_number

print error_type$

print error_line
