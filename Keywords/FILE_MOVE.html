FILE_MOVE F1,F2

FILE_MOVE F1,F2

DÉPLACE LE FICHIER EXISTANT F1 DANS LE NOUVEAU FICHIER F2


  • Type : Commande
  • Paramètres : 2
  • Groupe : Fichiers


ACTION

La commande FILE_MOVE F1,F2 déplace le fichier existant F1 dans le nouveau fichier F2. Il y a une erreur si le fichier F2 existe déjà.

F1 et F2 sont des noms de fichier absolus ou relatifs.

Le nom absolu du fichier est le nom complet, par rapport à la racine du système de fichier (ex : "c:\temp\file.txt").

Le nom relatif est le nom du fichier par rapport au répertoire courant (ex : "file.txt" ou "/file.txt" ou "\file.txt").


SYNTAXE : FILE_MOVE F1,F2

  • F1 et F2 = noms absolu ou relatif du fichier.

UTILISATION

  • La commande FILE_MOVE est utilisée pour déplacer un fichier.

ERREUR

  • Si le fichier F1 n'existe pas.
  • Si le fichier F2 existe déjà.
  • Si F1 ou F2 n'est pas un nom correct de fichier.

EXEMPLE

FILE_MOVE.bas 
' déplacer le fichier "test.txt" en "test2.txt"
file_move "test.txt","test2.txt"
