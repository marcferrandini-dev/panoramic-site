OFF_MOUSE_DOWN N

OFF_MOUSE_DOWN N

IGNORE L'ÉVÉNEMENT "MOUSE_DOWN" QUAND L'UTILISATEUR PRESSE UNE TOUCHE DE LA SOURIS SUR L'OBJET SYSTÈME NUMÉRO N


  • Type : Commande
  • Paramètre : 1
  • Groupe : Evénements


ACTION

La commande OFF_MOUSE_DOWN N ignore l'événement "mouse_down" sur l'objet système désigné par le numéro N : le sous-programme de traitement d'événement n'est pas exécuté quand l'utilisateur presse une touche de la souris et que la souris est sur l'objet système.

Remarque 1 : l'objet système doit être de l'un des types suivants : SCENE3D, BUTTON , EDIT, MEMO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, PROGRESS_BAR, SPIN, GRID, CONTAINER, SCENE2D, PANEL, CONTAINER_TAB, TAB.

Remarque 2 : le sous-programme de traitement d'événement est défini par la commande ON_MOUSE_DOWN N,L qui assigne le label L comme point de départ du sous-programme de traitement d'événement.


SYNTAXE : OFF_MOUSE_DOWN N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande OFF_MOUSE_DOWN est utilisée pour ne pas traiter l'événement "MOUSE_DOWN" arrivant à un objet système : quand l'événement arrive, le sous-programme de traitement d'événement n'est pas exécuté.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : SCENE3D, BUTTON , EDIT, MEMO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, PROGRESS_BAR, SPIN, GRID, CONTAINER, SCENE2D, PANEL, CONTAINER_TAB, TAB.

EXEMPLE

OFF_MOUSE_DOWN.bas 
label down, up
button 1
left 1,300
width 1,200
on_mouse_up 1, down
on_mouse_up 1, up
caption 0,"Appuyez et relâchez une touche de la souris sur le Button"
end
down:
caption 0,"DOWN sur BUTTON"
pause 1000:caption 0,""
off_mouse_down 1
return
up:
caption 0,"UP sur BUTTON"
pause 1000:caption 0,""
off_mouse_up 1
return
