EXECUTE F [Pi]

EXECUTE F [Pi]

EXÉCUTE LE FICHIER F AVEC DES PARAMETRES OPTIONNELS


  • Type : Commande
  • Paramètres : n
  • Groupe : Système


ACTION

La commande EXECUTE F exécute le fichier F. F est le nom absolu ou relatif du fichier à exécuter ou le nom d'une URL. Dans ce cas, le nom doit commencer par "http://" et la commande EXECUTE utilise le navigateur internet par défaut. Par exemple pour visualiser le forum de PANORAMIC, la commande est :

execute "http://panoramic.free-boards.net"

Le nom absolu du fichier est le nom complet, par rapport à la racine du système de fichier (ex : "c:\temp\file.exe").

Le nom relatif est le nom du fichier par rapport au répertoire courant (ex : "file.exe" ou "/file.exe" ou "\file.exe").

La commande peut passer un ou plusieurs paramètres au fichier exécutable F. Les paramètres doivent être séparés du nom de l'exécutable par le caractère |. Les paramètres sont séparés par des espaces.

Exemple : EXECUTE "Make_exe.exe|-e source.bas" lance l'exécutable "Make_exe.exe" et lui passe 2 paramètres "-e" et "source.bas".


SYNTAXE : EXECUTE F / EXECUTE F Pi

  • SYNTAXE 1 :
  • EXECUTE F
  • F = nom absolu ou relatif du fichier.
  • SYNTAXE 2 :
  • EXECUTE F P1 P2 ...
  • F = nom absolu ou relatif du fichier.
  • Pi = paramètre.

UTILISATION

  • La commande EXECUTE est utilisée pour exécuter un fichier.

ERREUR

  • Si F n'est pas un nom correct de fichier.

EXEMPLE

EXECUTE.bas 
' lancer le programme prg.exe
execute "prg.exe"
' lancer le programme prog.exe et lui passer un paramètre
execute "prog.exe 50"

EN RAPPORT

EXECUTE_WAIT
