PARALLEL_INP(A)

PARALLEL_INP(A)

RETOURNE LA VALEUR LUE SUR LE PORT PARALLÈLE D'ADRESSE A


  • Type : Fonction
  • Paramètre : 1
  • Groupe : Entrées-Sorties


ACTION

La fonction PARALLEL_INP(A) retourne la valeur lue sur le port parallèle d'adresse A.

A peut être un réel ou un entier. Si A est une valeur réelle, elle est arrondie à l'entier le plus proche avant l'opération de lecture.


SYNTAXE : Resultat=PARALLEL_INP(A)

  • A = adresse du port parallèle (entier ou réel)

UTILISATION

  • La fonction PARALLEL_INP() est utilisée pour lire une valeur sur la prise imprimante.

ERREUR

  • Si la commande PARALLEL_ON n'a pas été exécutée.
  • Si A est inférieur à 0.
  • Si A est plus grand que 1000.

EXEMPLE

PARALLEL_INP().bas 
' démarre les opérations d'entrées-sorties
parallel_on
' met tous le bits à 1 sur le port de données
parallel_out 888,255
' lecture du port d'état
print parallel_inp(889)
' arrête les opérations d'entrées-sorties
parallel_off
