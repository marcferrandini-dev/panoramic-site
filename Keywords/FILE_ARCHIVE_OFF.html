FILE_ARCHIVE_OFF F

FILE_ARCHIVE_OFF F

RETIRE L'ATTRIBUT "ARCHIVE" DU FICHIER F


  • Type : Commande
  • Paramètre : 1
  • Groupe : Fichiers


ACTION

La commande FILE_ARCHIVE_OFF F retire l'attribut "archive" du fichier F.

Remarque : la commande FILE_ARCHIVE F positionne l'attribut "archive" du fichier F.

F est le nom absolu ou relatif du fichier.

Le nom absolu du fichier est le nom complet, par rapport à la racine du système de fichier (ex : "c:\temp\file.txt").

Le nom relatif est le nom du fichier par rapport au répertoire courant (ex : "file.txt" ou "/file.txt" ou "\file.txt").


SYNTAXE : FILE_ARCHIVE_OFF F

  • F = nom absolu ou relatif du fichier.

UTILISATION

  • La commande FILE_ARCHIVE_OFF est utilisée pour rendre un fichier non "archive".

ERREUR

  • Si le fichier F n'existe pas.
  • Si F n'est pas un nom correct de fichier.

EXEMPLE

FILE_ARCHIVE_OFF.bas 
' retire la marque "archive" du fichier "test.txt"
file_archive_off "test.txt"
