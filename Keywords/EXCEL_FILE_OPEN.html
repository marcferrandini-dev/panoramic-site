EXCEL_FILE_OPEN N,F

OUVRE LE FICHIER (FEUILLE) EXISTANT F ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type: Commande
  • Paramètres: 2
  • Groupe: Excel


ACTION

La commande EXCEL_FILE_OPEN N,F ouvre un fichier existant avec le logiciel Microsoft Excel, s'il est en fonction.

N est le numéro du fichier EXCEL sur lequel portent les commandes : c'est le fichier cible.

F est son nom.

Un fichier est une feuille dans le vocabulaire Excel. Il est possible d'ouvrir plusieurs feuilles simultanément: elles sont identifiées par leur numéro.


SYNTAXE : EXCEL_FILE_OPEN N,F

  • N = numéro de fichier Excel (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis de fichiers Excel.
  • F = chemin du fichier (chaîne de caractères) à ouvrir.

UTILISATION

  • La commande est utilisée pour ouvrir une feuille existante avec Microsoft Excel.

ERREUR

  • Si le logiciel Excel n'est pas lancé.
  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le maximum de fichiers permis.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le fichier numéro N est en cours d'utilisation.
  • Si F n'est pas une expression correcte.

EXEMPLE

' lancer le logiciel Excel

excel_start

' attendre 5 secondes

wait 5000

' ouvrir un fichier existant

excel_file_open 1,"MonFichier.xls"

' attendre 5 secondes

wait 5000

' fermer ce fichier

excel_file_close 1

' arrêter le logiciel Excel

excel_stop
