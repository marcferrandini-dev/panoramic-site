PARALLEL_ON

PARALLEL_ON

DEMARRE LES OPÉRATIONS D'ENTRÉES-SORTIES SUR PORT PARALLÈLE


  • Type : Commande
  • Paramètre : 0
  • Groupe : Entrées-Sorties


ACTION

La commande PARALLEL_ON démarre les opérations d'entrées-sorties sur port parallèle.

La DLL inpout est chargée en mémoire et les opérations d'entrées-sorties deviennent possibles : sortie avec PARALLEL_OUT et entrée avec PARALLEL_INP.

La DLL doit être dans le même répertoire que l'exécutable, soit dans le répertoire Windows, avec toutes les DLL du système.


SYNTAXE : PARALLEL_ON


UTILISATION

  • La commande PARALLEL_ON est utilisée pour démarrer les entrées-sorties sur la prise imprimante.

ERREUR

  • Si une commande PARALLEL_ON a déja été exécutée (la commande PARALLEL_OFF arrête les opérations d'entrée-sortie).
  • Si la DLL inpout n'est pas accessible.

EXEMPLE

PARALLEL_ON.bas 
' démarre les opérations d'entrées-sorties
parallel_on
' met tous le bits à 1 sur le port de données
parallel_out 888,255
' lecture du port d'état
print parallel_inp(889)
' arrête les opérations d'entrées-sorties
parallel_off
