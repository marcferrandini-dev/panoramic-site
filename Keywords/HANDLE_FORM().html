HANDLE_FORM(T)

HANDLE_FORM(T)

RETOURNE LE HANDLE D'UN FORM (PANORAMIC OU PAS) DONT LE TITRE (CAPTION) EST CONNU


  • Type : Fonction
  • Paramètre : 1
  • Groupe : Système


ACTION

La fonction HANDLE_FORM(T) retourne le handle d'un FORM (PANORAMIC ou pas) dont on connait le titre T (caption).

Si le FORM n'existe pas ou s'il n'y a pas de FORM ayant T comme caption, le résultat vaut 0.

Le handle est le numéro donné par le système d'exploitation (Windows) à un objet.


SYNTAXE : Resultat=HANDLE_FORM(T)

  • T = chaîne de caractères

UTILISATION

  • La fonction HANDLE_FORM() est utilisée pour connaître le handle d'un FORM dont on connait le titre.

ERREUR

  • Si T n'est pas une expression chaîne correcte.

EXEMPLE

HANDLE_FORM().bas 
form 1
left 1,100
caption 1,"Form 1"
caption 0,handle_form("Form 1")

EN RAPPORT

FORM
