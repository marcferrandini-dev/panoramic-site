KEY_UP_CODE

KEY_UP_CODE

RETOURNE LE CODE DE LA TOUCHE QUE l'UTILISATEUR RELACHE


  • Type : Variable système
  • Paramètre : 0
  • Groupe : Evénements


ACTION

La variable système KEY_UP_CODE retourne le code de la touche que l'utilisateur relâche. Elle n'est utilisable que dans un traitement de l'événement ON_KEY_UP arrivant sur un objet système.

La variable système est associée à KEY_UP_SPECIAL qui indique si les touches CTRL, SHIFT ou ALT ont été utilisées en même temps.


SYNTAXE : Resultat=KEY_UP_CODE


UTILISATION

  • La variable système KEY_UP_CODE est utilisée dans le traitement de l'événement ON_KEY_UP pour connaître le code de la touche relâchée.

ERREUR

  • Rien.

EXEMPLE

KEY_UP_CODE.bas 
' déclarer un label
label enter_key
' un EDIT est créé
edit 1:set_focus 1
' chaque fois qu'une touche est relâchée dans l'EDIT, exécuter à partir du label "enter_key"
on_key_up 1,enter_key
end: ' le programme principal est fini
enter_key:
' treatment of event
if key_up_code=13 then caption 0,"ENTER est relaché"
return
