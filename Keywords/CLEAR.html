CLEAR N

CLEAR N

EFFACE LE CONTENU DE L'OBJET SYSTÈME NUMÉRO N


  • Type : Commande
  • Paramètre : 1
  • Groupe : Objets Système


ACTION

La commande CLEAR N efface le contenu de l'objet système désigné par son numéro N.

L'objet système est du type : MEMO, COMBO, LIST, MEMO_RICH, DLIST, HVIEWER, SYNEDIT.


SYNTAXE : CLEAR N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande CLEAR est utilisée pour effacer un MEMO, COMBO, LIST, MEMO_RICH, DLIST, HVIEWER, SYNEDIT.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : MEMO, COMBO, LIST, MEMO_RICH, DLIST, HVIEWER, SYNEDIT.

EXEMPLE

CLEAR.bas 
' créer un MEMO
memo 1
' le remplir avec une ligne
item_add 1,"Salut!"
' attendre 1 seconde
wait 1000
' effacer son contenu
clear 1
