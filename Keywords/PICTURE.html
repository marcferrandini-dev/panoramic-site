PICTURE N

PICTURE N

CRÉE UN OBJET SYSTÈME PICTURE ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type : Commande
  • Paramètre : 1
  • Groupe : Création Objets Système


ACTION

La commande PICTURE N crée un objet système PICTURE et lui donne un numéro N. Le numéro N sera utilisé pour désigner ce PICTURE.

Le PICTURE créé peut alors être utilisé par les commandes appropriées.

Le PICTURE est créé à la position (0,0) : c'est à dire TOP = 0 pixel et LEFT = 0 pixel, avec les dimensions : WIDTH = 105 pixels et HEIGHT = 105 pixels.

Un PICTURE visualise un fichier bitmap avec la commande FILE_LOAD.

Un PICTURE peut générer les événements : ON_CLICK, ON_DOUBLE_CLICK.

Remarque : par défaut, le PICTURE est créé sur le FORM numéro 0, mais un autre FORM peut être utilisé. Pour cela, créer un FORM par FORM N et lui envoyer les commandes par COMMAND_TARGET_IS N avant la création du PICTURE.


SYNTAXE : PICTURE N

  • N = numéro d'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • Un PICTURE est utilisé pour visualiser un fichier bitmap (avec la commande FILE_LOAD).

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le numéro N est déjà utilisé pour un numéro d'objet système.

EXEMPLE

PICTURE.bas 
' crée un PICTURE avec la position et les dimensions par défaut 
picture 1
' visualise le fichier bitmap
file_load 1,"landscape.bmp"
