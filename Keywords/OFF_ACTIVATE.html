OFF_ACTIVATE N

IGNORE L'ÉVÉNEMENT "ACTIVATE" QUAND L'OBJET SYSTÈME NUMÉRO N (FORM) EST ACTIVÉ


  • Type: Commande
  • Paramètre: 1
  • Groupe: Evénements


ACTION

La commande OFF_ACTIVATE N ignore l'événement "activate" sur l'objet système désigné par le numéro N: le sous-programme de traitement d'événement n'est pas exécuté.

Remarque 1: l'objet système doit être de type FORM.

Remarque 2: le sous-programme de traitement d'événement est défini par la commande ON_ACTIVATE N,L qui assigne le label L comme point de départ du sous-programme de traitement d'événement.


SYNTAXE : OFF_ACTIVATE N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande OFF_ACTIVATE est utilisée pour ne plus associer l'événement "activate" arrivant à un FORM, à un emplacement de programme (défini par le label L).
  • Quand l'événement arrive, le programme marqué par le label n'est plus exécuté.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : FORM.

EXEMPLE

OFF_ACTIVATE.bas 
label active0,active1
dim k0%,k1%
k0%=0
k1%=0
height 0,200:width 0,300
alpha 10:top 10,20:left 10,20:caption 10, "Cliquez sur ce FORM"
form 1:left 1,310:height 1,200:width 1,300
alpha 11:parent 11,1:top 11,20:left 11,20
on_activate 0,active0
on_activate 1,active1
end
active0:
k0%=k0%+1
caption 0, "nombre d'activations: "+str$(k0%)+" : "+str$(NUMBER_ACTIVATE)
caption 10, ""
caption 11, "Cliquez sur ce FORM"
off_activate 0
return
active1:
k1%=k1%+1
caption 1, "nombre d'activations: "+str$(k1%)+" : "+str$(NUMBER_ACTIVATE)
caption 10, "Cliquez sur ce FORM"
caption 11, ""
off_activate 1
return
