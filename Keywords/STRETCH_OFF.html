STRETCH_OFF N

STRETCH_OFF N

ARRÊTE LE REDIMENSIONNEMENT AUTOMATIQUE DE L'IMAGE VISUALISÉE PAR L'OBJET SYSTÈME NUMÉRO N


  • Type : Commande
  • Paramètre : 1
  • Groupe : Objets Système


ACTION

La commande STRETCH_OFF N arrête le redimensionnement automatique de l'image visualisée par l'objet système désigné par son numéro N : l'image visualisée reprend sa propre forme.

L'objet système est un PICTURE ou un SCENE2D.

Remarque : le redimensionnement automatique est démarré par la commande STRETCH_ON.


SYNTAXE : STRETCH_OFF N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande STRETCH_OFF est utilisée pour revenir à la forme initiale de l'image visualisée par un PICTURE ou un SCENE2D.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : PICTURE, SCENE2D.

EXEMPLE

STRETCH_OFF.bas 
' créer un SCENE2D avec la position et les dimensions par défaut 
scene2d 1
' charge une image de fond
file_load 1,"Mon monde 2D.bmp"
' démarre le redimensionnement automatique
stretch_on 1
' changer les dimensions du SCENE2D
width 1,600
height 1,400
' attendre 1 seconde
wait 1000
' arrêter le redimensionnement automatique
stretch_off 1

EN RAPPORT
