TRACK_BAR N

TRACK_BAR N

CRÉE UN OBJET SYSTÈME TRACK_BAR ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type : Commande
  • Paramètre : 1
  • Groupe : Création Objets Système


ACTION

La commande TRACK_BAR N crée un objet système TRACK_BAR et lui donne un numéro N. Le numéro N sera utilisé pour désigner ce TRACK_BAR.

Le TRACK_BAR créé peut alors être utilisé par les commandes appropriées.

Le TRACK_BAR est créé à la position (0,0) : c'est à dire TOP = 0 pixel et LEFT = 0 pixel, avec les dimensions WIDTH = 150 pixels et HEIGHT = 45 pixels.

Un TRACK_BAR visualise une glissière avec des marqueurs. La glissière peut être positionnée par la commande POSITION N,P et sa position peut être lue par la fonction POSITION(N).

Un TRACK_BAR peut générer l'événement : ON_CHANGE.

Remarque : par défaut, le TRACK_BAR est créé sur le FORM numéro 0, mais un autre FORM peut être utilisé. Pour cela, créer un FORM par FORM N et lui envoyer les commandes par COMMAND_TARGET_IS N avant la création du TRACK_BAR.


SYNTAXE : TRACK_BAR N

  • N = numéro d'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • Un TRACK_BAR est utilisé pour visualiser une glissière avec des marqueurs. La glissière peut être positionnée par la commande POSITION et sa position peut être lue par la fonction POSITION().

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le numéro N est déjà utilisé pour un numéro d'objet système.

EXEMPLE

TRACK_BAR.bas 
' crée un TRACK_BAR avec la position et les dimensions par défaut 
track_bar 1
