O3D_OBJECT_TYPE(N)

RETOURNE LE TYPE DE L'OBJET 3D NUMÉRO N


  • Type: Fonction
  • Paramètre: 1
  • Groupe: Objets 3D


ACTION

La fonction O3D_OBJECT_TYPE(N) retourne le type de l'objet 3D numéro N.

Le type d'un objet 3D est codé:

1=3D_CUBE

2=3D_BOX

3=3D_SPHERE

4=3D_CONE

5=3D_TORUS

6=3D_CYLINDER

7=3D_DODECAHEDRON

8=3D_TEAPOT

9=3D_TEXT

10=3D_LINE

11=3D_MESH

12=3D_ACTOR

14=3D_SKYBOX

16=3D_PLANE

La fonction O3D_OBJECT_TYPE(N) retourne -1 si l'objet 3D numéro N n'existe pas.


SYNTAXE : Resultat=O3D_OBJECT_TYPE(N)

  • N = numéro de l'objet système (entier ou réel).

UTILISATION

  • La fonction O3D_OBJECT_TYPE() est utilisée pour connaître le type d'un objet 3D.

ERREUR

  • Si le numéro N n'est pas une expression correcte.

EXEMPLE

' créer un SCENE3D

scene3d 1

' créer un objet 3D dans ce scene3d

3d_teapot 1

' afficher son type comme titre

caption 0, o3d_object_type(1)
