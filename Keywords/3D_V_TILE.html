3D_V_TILE N,T

3D_V_TILE N,T

MODIFIE LE NOMBRE DE TUILES SUR V DU 3D_PLANE NUMÉRO N


  • Type: Commande
  • Paramètres: 2
  • Groupe: Objets 3D


ACTION

La commande 3D_V_TILE N,T modifie le nombre de tuiles qui compose la texture de l'objet 3D_PLANE désigné par son numéro N, pour la coordonnée V. C'est le nombre de tuiles de texture sur l'axe V.


SYNTAXE : 3D_V_TILE N,T

  • N = numéro d'objet 3D (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets 3D.
  • T = nombre de tuiles.

UTILISATION

  • La commande 3D_V_TILE est utilisée pour modifier le nombre de tuiles sur V.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets 3D.
  • Si le numéro N est inférieur ou égal à 0.
  • Si l'objet 3D numéro N n'existe pas.
  • Si T n'est pas une expression correcte.
  • Si T est inférieur ou égal à 0

EXEMPLE

3D_V_TILE.bas 
' crée un monde 3D
scene3d 1
' place la caméra
cam_z_position 10
' crée un OBJET 3D_PLANE numéro 1
3d_plane 1
' charge une texture
3d_load_texture 1,"picture.bmp"
' positionne l'objet
3d_z_position 1,-5
' modifie le nombre de tuiles
3d_u_tile 1,10
3d_v_tile 1,5
