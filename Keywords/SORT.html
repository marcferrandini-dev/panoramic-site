SORT N

SORT N

TRIE LE CONTENU DE L'OBJET SYSTÈME NUMÉRO N


  • Type : Commande
  • Paramètre : 1
  • Groupe : Objets Système


ACTION

La commande SORT N trie par ordre ascendant les articles de l'objet système désigné par son numéro N.

Remarque : La commande est à renouveler à chaque fois que le contenu de l'objet système doit être trié.


SYNTAXE : SORT N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande SORT est utilisée pour trier le contenu d'un objet système COMBO, LIST ou DLIST.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : COMBO, LIST, DLIST.

EXEMPLE

SORT.bas 
' créer un LIST
list 1
' lui ajouter 3 articles
item_add 1,"BBB"
item_add 1,"CCC"
item_add 1,"AAA"
' trier le contenu
sort 1
' ajouter un article
item_add 1,"ABC"
' l'ordre est : AAA,BBB,CCC,ABC
