FILE_EXTRACT_PATH$(F)

RETOURNE UN CHEMIN DE FICHIER ì PARTIR DE F


  • Type: Fonction
  • Paramètre: 1
  • Groupe: Fichiers


ACTION

La fonction FILE_EXTRACT_PATH$(F) retourne un chemin de fichier à partir de l'expression F.

Le résultat est significatif quand F est un nom absolu de fichier.

S'il n'y a pas de chemin dans l'expression F, une chaîne vide est retournée.


SYNTAXE : Resultat$=FILE_EXTRACT_PATH$(F)

  • F = nom de fichier.
  • Resultat$ est une chaîne de caractères.

UTILISATION

  • La fonction FILE_EXTRACT_PATH$() est utilisée pour extraire un chemin de fichier à partir d'une chaîne de caractères.

ERREUR

  • Si F n'est pas un nom correct de fichier.

EXEMPLE

' crée un OPEN_DIALOG pour choisir un fichier

open_dialog 1

' affiche dans le bandeau le chemin du fichier choisi

caption 0,file_extract_path$(file_name$(1))
