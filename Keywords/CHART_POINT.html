CHART_POINT N

CHART_POINT N

L'OBJET CHART NUMÉRO N AFFICHE LES DONNÉES SOUS FORME DE POINTS


  • Type: Commande
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La commande CHART_POINT N modifie le graphique affiché par l'objet CHART numéro N, qui devient des points.

Par défaut, un CHART affiche une ligne.


SYNTAXE : CHART_POINT N

  • N = numéro d'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande CHART_LINE est utilisée pour faire afficher des points par un objet CHART.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet numéro N n'est pas du type : CHART.

EXEMPLE

CHART_POINT.bas 
' créer un CHART avec sa position et sa dimension par défaut
