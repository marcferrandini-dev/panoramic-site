NUMERIC(V)

NUMERIC(V)

RETOURNE 1 SI V$ REPRÉSENTE UNE VALEUR NUMÉRIQUE, 0 SINON


  • Type : Fonction
  • Paramètre : 1
  • Groupe : Mathématiques


ACTION

La fonction NUMERIC(V) retourne 1 si V$ représente une valeur numérique, 0 sinon.

V est un réel ou un entier.

Remarque : une chaîne de caractères contenant une valeur numérique peut être convertie en un nombre par la fonction VAL.


SYNTAXE : Resultat=NUMERIC(V)

  • V = valeur réelle ou entière.

UTILISATION

  • La fonction NUMERIC() est utilisée pour savoir si une chaîne de caractères peut être converti en un nombre.

ERREUR

  • Rien.

EXEMPLE

NUMERIC().bas 
print numeric("3.1")
print "Résultat = 1"

EN RAPPORT

VAL()
