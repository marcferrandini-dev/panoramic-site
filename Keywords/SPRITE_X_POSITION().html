SPRITE_X_POSITION(N)

RETOURNE LA COORDONNÉE EN X DU SPRITE NUMÉRO N


  • Type: Fonction
  • Paramètre: 1
  • Groupe: SPRITE


ACTION

La fonction SPRITE_X_POSITION(N) retourne la coordonnée X du SPRITE numéro N.

Les coordonnées X et Y d'un SPRITE sont des coordonnées "sur l'écran" dans le SCENE2D : la valeur X des coordonnées est la position horizontale sur le SCENE2D comptée de la gauche vers la droite X. La coordonnée Y est la position verticale sur le SCENE2D comptée du haut vers le bas.

Les coordonnées (0,0) sont celles du coin en haut à gauche du SCENE2D.


SYNTAXE : Resultat=SPRITE_X_POSITION(N)

  • N = numéro de SPRITE (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets SPRITE.

UTILISATION

  • La fonction SPRITE_X_POSITION() est utilisée pour connaitre la position horizontale d'un SPRITE sur son SCENE2D.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets SPRITES.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le SPRITE numéro N n'existe pas.

EXEMPLE

' créer un monde 2D numéro 1

scene2d 1

' charger une image de fond

file_load 1,"ville.bmp"

' créer un SPRITE numéro 1

sprite 1

' charger une image dans le SPRITE

sprite_file_load 1,"envahisseur.bmp"

' positionner le SPRITE sur le SCENE2D

sprite_x_position 1,150

sprite_y_position 1,250

' afficher la position du SPRITE

print sprite_x_position(1)

print sprite_y_position(1)
