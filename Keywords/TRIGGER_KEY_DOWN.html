TRIGGER_KEY_DOWN N,C,S

SIMULE L'ÉVÉNEMENT ON_KEY_DOWN SUR L'OBJET SYSTÈME NUMÉRO N


  • Type: Commande
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La commande TRIGGER_KEY_DOWN N,C,S simule l'événement clavier produit par l'appui sur une touche ON_KEY_DOWN sur l'objet système numéro N.

C est le code de la touche simulée.

S est un code pour simuler une touche composée:

0 pour touche simple

1 pour SHIFT

2 pour ALT

3 pour CONTROL

4 pour SHIFT + ALT

5 pour SHIFT + CONTROL

6 pour ALT + CONTROL


SYNTAXE : TRIGGER_KEY_DOWN N,C,S

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • C = code de la touche (entier ou réel).
  • S = code de combinaison de touche (entier ou réel).

UTILISATION

  • La commande TRIGGER_KEY_DOWN est utilisée pour simuler l'événement ON_KEY_DOWN sur un objet système.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si l'objet numéro N n'est pas du type : BUTTON, EDIT, MEMO, COMBO, FORM, LIST, CHECK, OPTION, SPIN, GRID, MEMO_RICH, BUTTON_PICTURE, SCENE2D, GRID_DRAW, SYNEDIT.
  • Si C n'est pas une expression correcte.
  • Si S n'est pas une expression correcte.

EXEMPLE

label keydown

edit 1

on_key_down 1,keydown

wait 1000

trigger_key_down 1,65,1

end

keydown:

caption 0,"KEY DOWN fait: "+CHR$(key_down_code)+" "+STR$(key_down_special)

return
