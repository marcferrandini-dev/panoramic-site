SCENE2D N

CRÉE UN SCENE2D ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type: Commande
  • Paramètre: 1
  • Groupe: Création Objets Système


ACTION

La commande SCENE2D N crée un SCENE2D pour visualiser un univers 2D et lui donne un numéro N. Le numéro N sera utilisé pour désigner ce SCENE2D.

Un SCENE2D peut visualiser une image en arrière-plan et peut accueillir des SPRITES. Un SCENE2D et des SPRITES sont la base d'un jeu vidéo en 2D. Les SPRITES peuvent être déplacés, cachés, visualisés sans perturber l'image de fond du SCENE2D, ils possèdent une couleur "transparente", non visualisée.

Le SCENE2D est créé à la position (0,0) : c'est à dire TOP = 0 pixel et LEFT = 0 pixel, avec les dimensions WIDTH = 200 pixels et HEIGHT = 200 pixels.

Un SCENE2D peut générer l'événement : ON_CLICK.

Remarque : par défaut, le SCENE2D est créé sur le FORM numéro 0, mais un autre FORM peut être utilisé. Pour cela, créer un FORM par FORM N et lui envoyer les commandes par COMMAND_TARGET_IS N avant la création du SCENE2D.


SYNTAXE : SCENE2D N

  • N = numéro d'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • Un SCENE2D est utilisé pour manipuler un monde 2D avec une image de fond et des SPRITES.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le numéro N est déjà utilisé pour un numéro d'objet.

EXEMPLE

' crée un SCENE2D avec la position et les dimensions par défaut

scene2D 1

' charge une image de fond

file_load 1,"Mon monde 2D.bmp"

' change les dimensions du SCENE2D

width 1,600

height 1,400
