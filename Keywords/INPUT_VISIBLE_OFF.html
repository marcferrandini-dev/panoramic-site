INPUT_VISIBLE_OFF

INPUT_VISIBLE_OFF

N'AFFICHE PAS LES CARACTÈRES SAISIS LORS D'UNE COMMANDE INPUT


  • Type : Commande
  • Paramètre : 0
  • Groupe : Système


ACTION

Lors de l'exécution d'une commande INPUT, les caractères saisis ne sont pas affichés sur l'objet système "récepteur des impressions".

Par défaut, le "récepteur des impressions" est FORM0, mais un objet système devient "récepteur des impressions" par la commande PRINT_TARGET_IS.

La commande INPUT_VISIBLE_OFF est active uniquement si le moyen d'entrée est le clavier.


SYNTAXE : INPUT_VISIBLE_OFF


UTILISATION

  • La commande INPUT_VISIBLE_OFF est utilisée pour ne pas afficher les caractères saisis au clavier lors de l'exécution d'une commande INPUT.

ERREUR

  • Rien.
