RMDIR D

RMDIR D

DÉTRUIT LE RÉPERTOIRE VIDE D


  • Type: Commande
  • Paramètre: 1
  • Groupe: Répertoires


ACTION

La commande RMDIR D détruit le répertoire D. D est le nom absolu ou relatif du répertoire.

Si D est un nom relatif, D est considéré comme un sous-répertoire du répertoire courant.

Le nom absolu du répertoire est le nom complet, par rapport à la racine du système de fichier (ex: "c:\temp\files\" ou "c:\temp\files").

Le nom relatif est le nom du répertoire par rapport au répertoire courant (ex: "files").

Remarque 1 : D doit être un répertoire vide, ne contenant aucun fichier.

Remarque 2 : les commandes DIR_REMOVE et RMDIR ont exactement le même effet.


SYNTAXE : RMDIR D

  • D = nom absolu ou relatif du répertoire.

UTILISATION

  • La commande RMDIR est utilisée pour détruire un répertoire vide.

ERREUR

  • Si D n'est pas un nom correct de répertoire.

EXEMPLE

RMDIR.bas 
' détruire le répertoire "abcd"
rmdir "abcd"

EN RAPPORT

DIR_REMOVE
