EXCEL_READ$(C)

LIT LE CONTENU DE LA CELLULE C DE LA FEUILLE COURANTE AVEC MICROSOFT EXCEL


  • Type: Fonction
  • Paramètre: 1
  • Groupe: Excel


ACTION

La fonction EXCEL_READ$(C) rend une chaîne de caractères qui est le contenu de la cellule définie par C dans la feuille de calcul courante de Microsoft Excel, s'il est en fonction.

Remarque: le mot-clé EXCEL_READ$ se termine par '$' : cela veut dire que la valeur retournée est du type chaîne de caractères.


SYNTAXE : Resultat$=EXCEL_READ$(C)

  • C: chaîne de caractères représentant les coordonnées d'une cellule (Exemple : "B2")
  • Resultat$ est une chaîne de caractères

UTILISATION

  • La fonction EXCEL_READ$() est utilisée pour lire le contenu d'une cellule dans une feuille de Microsoft Excel.

ERREUR

  • Si C n'est pas une expression string correcte.
  • Si le logiciel d'Excel n'est pas lancé.
  • Si aucune feuille (fichier) n'est ouverte.

EXEMPLE

' lancer le logiciel Excel

excel_start

' attendre 5 secondes

wait 5000

' créer un nouveau fichier

excel_file_new 1

' écrire "Salut" dans la cellule A1

excel_write "A1","Salut"

' imprimer le contenu de la cellule A1

print excel_read$("A1")
