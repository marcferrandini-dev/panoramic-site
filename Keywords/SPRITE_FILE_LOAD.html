SPRITE_FILE_LOAD N,F

CHARGE L'IMAGE DU FICHIER F (FORMAT BMP) DANS LE SPRITE NUMÉRO N


  • Type: Commande
  • Paramètres: 2
  • Groupe: SPRITE


ACTION

La commande SPRITE_FILE_LOAD N,F charge une image dans le SPRITE numéro N.

Le fichier doit être dans le format BMP.


SYNTAXE : SPRITE_FILE_LOAD N,F

  • N = numéro de SPRITE (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets SPRITE.
  • F = nom (absolu ou relatif) du fichier contenant l'image.

UTILISATION

  • La commande est utilisée pour charger une image (format BMP) dans un SPRITE.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le SPRITE numéro N n'existe pas.
  • Si F n'est pas une expression string correcte.
  • Si le fichier F n'existe pas.

EXEMPLE

' créer un monde 2D numéro 1

scene2d 1

' charger une image de fond

file_load 1,"ville.bmp"

' créer un SPRITE numéro 1

sprite 1

' charger une image dans le SPRITE

sprite_file_load 1,"envahisseur.bmp"
