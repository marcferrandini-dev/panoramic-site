BIN_OR(V1,V2)

RETOURNE LE "OU" LOGIQUE BINAIRE ENTRE LES VALEURS V1 ET V2


  • Type: Fonction
  • Paramètres: 2
  • Groupe: Mathématiques


ACTION

La fonction BIN_OR(V1,V2) retourne la valeur du "OU" logique binaire entre V1 et V2.

V1 et V2 sont des données ou des variables qui peuvent être réelles ou entières.

Si une valeur est réelle, elle est arrondie à l'entier le plus proche avant l'opération logique.

L'opération logique est faite bit à bit:

1 OU 1 = 1

1 OU 0 = 1

0 OU 1 = 1

0 OU 0 = 0

Application:

pour imposer un bit à 1

Après V1=BIN_OR(V1,1), la variable V1 a son bit de poids faible qui est mis à 1, sans modifier les autres bits.


SYNTAXE : Resultat=BIN_OR(V1,V2)

  • V1 = valeur entière ou réelle.
  • V2 = valeur entière ou réelle.

UTILISATION

  • La fonction BIN_OR() est utilisée pour forcer un bit à 1.

ERREUR

  • Si V1 ou V2 ne sont pas des expressions correctes.

EXEMPLE

print bin_or(3,5)

print "Résultat = 7"
