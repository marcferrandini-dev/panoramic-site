STRETCH_ON N

STRETCH_ON N

DÉMARRE LE REDIMENSIONNEMENT AUTOMATIQUE DE L'IMAGE VISUALISÉE PAR L'OBJET SYSTÈME NUMÉRO N


  • Type: Commande
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La commande STRETCH_ON N redimensionne l'image visualisée par l'objet système désigné par son numéro N à la forme de cet objet système. Comme la hauteur et la largeur de l'image sont redimensionnés indépendamment, l'image visualisée par l'objet système peut subir une distorsion.

Le redimensionnement est automatique : quand l'objet système est redimensionné par les commandes HEIGHT et WIDTH, l'image visualisée est aussi redimensionnée.

L'objet système est un PICTURE ou un SCENE2D.

Remarque: le redimensionnement automatique peut être arrêté par la commande STRETCH_OFF.


SYNTAXE : STRETCH_ON N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande STRETCH_ON est utilisée pour redimensionner automatiquement l'image visualisée par un PICTURE ou un SCENE2D.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : PICTURE, SCENE2D.

EXEMPLE

STRETCH_ON.bas 
' créer un SCENE2D avec la position et les dimensions par défaut 
scene2d 1
' charge une image de fond
file_load 1,"Mon monde 2D.bmp"
' démarre le redimensionnement automatique
stretch_on 1
' changer les dimensions du SCENE2D
width 1,600
height 1,400
' attendre 1 seconde
wait 1000
' arrêter le redimensionnement automatique
stretch_off 1

EN RAPPORT

STRETCH_OFF
