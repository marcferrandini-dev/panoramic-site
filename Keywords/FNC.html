FNC F

DEFINIT LA FONCTION F


  • Type: Commande
  • Paramètres: n
  • Groupe: Structures


ACTION

La commandeFNC F commence la fonction appelée F.

Une fonction est un groupe d'instructions qui peut être appelé dans une expression et qui retourne un résultat par la commande RESULT.

Les fonctions sont typées comme les variables :

- si le nom d'une fonction se termine par %, elle retourne un entier

- si le nom d'une fonction se termine par $, elle retourne une chaine de caractères

- si le nom d'une fonction se termine par une lettre ou un chiffre, elle retourne un réel


SYNTAXE : FNC F(P1, P2 ,⬦)

  • F : chaîne de caractères, nom de la fonction
  • P1, P2 : paramètres éventuels

UTILISATION

  • La commande FNC est utilisée pour définir une fonction.

ERREUR

  • Si le nom de la fonction n'est pas correct.
  • Si le nom de la fonction est déjà défini.
  • Si le nom d'un paramètre n'est pas correct.

EXEMPLE

dim i%

for i%=1 to 10

print double(i%)

next i%

end

fnc double(j%)

result 2*j%

end_fnc


EN RAPPORT

RESULT

END_FNC
