MIDI_PLAY N,T

JOUE LA NOTE N DE TYPE T SUR LA SORTIE MIDI


  • Type: Commande
  • Paramètres: 2
  • Groupe: MIDI


ACTION

La commande MIDI_PLAY N,T joue la note N de type T sur la sortie MIDI.

N suit la convention MIDI (60 = Do, 62 = Ré, ...) et doit être compris entre 21 et 108. N est la fréquence.

T est la durée de la note, de 0 à 11, définie comme suit:

0 : ronde, durée = 4000 millisecondes

1 : ronde pointée, durée = 6000 millisecondes

2 : blanche, durée = 2000 millisecondes

3 : blanche pointée, durée = 3000 millisecondes

4 : noire, durée = 1000 millisecondes

5 : noire pointée, durée = 1500 millisecondes

6 : croche, durée = 500 millisecondes

7 : croche pointée, durée = 750 millisecondes

8 : double croche, durée = 250 millisecondes

9 : double croche pointée, durée = 375 millisecondes

10: triple croche, durée = 125 millisecondes

11: triple croche pointée, durée = 188 millisecondes


SYNTAXE : MIDI_PLAY N,T

  • N = code MIDI de la note (entier ou réel).
  • T = code de la durée (entier ou réel).

UTILISATION

  • La commande MIDI_PLAY est utilisée pour jouer des notes individuelle sur une sortie MIDI.

ERREUR

  • Si la sortie MIDI n'a pas été ouverte (MIDI_ON).
  • Si la valeur N est inférieure à 21 ou supérieure à 108.
  • Si la valeur N n'est pas une expression correcte.
  • Si la valeur T est inférieure à 0 ou supérieure à 11.
  • Si la valeur T n'est pas une expression correcte.

EXEMPLE

midi_on

' suite de 2 noires Do, Ré

midi_play 60,4

midi_play 62,4

' suite de 3 croches Mi, Fa, Sol

midi_play 64,6

midi_play 65,6

midi_play 67,6

midi_off
