PLAY_WAIT N

PLAY_WAIT N

JOUE LE CONTENU DE L'OBJET SYSTÈME NUMÉRO N (SOUND OU MOVIE) ET ATTEND LA FIN


  • Type : Commande
  • Paramètre : 1
  • Groupe : Objets Système


ACTION

La commande PLAY_WAIT N joue le son ou le film chargé dans l'objet système désigné par son numéro N.

Quand c'est terminé, le programme continue.


SYNTAXE : PLAY_WAIT N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande PLAY_WAIT est utilisée pour jouer le fichier chargé dans un SOUND ou un MOVIE par la commande FILE_LOAD et suspendant le programme.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet système numéro N n'est pas du type : SOUND, MOVIE.

EXEMPLE

PLAY_WAIT.bas 
' créer un SOUND
sound 1
' charger un fichier son
file_load 1,"crack.wav"
' jouer le son
play_wait 1
print "c'est terminé"
