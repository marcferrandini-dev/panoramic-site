MAXIMIZE N

MAXIMISE LA TAILLE DU FORM NUMÉRO N


  • Type: Commande
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La commande MAXIMIZE N maximise l'objet système désigné par son numéro N.

L'objet système N est un FORM.


SYNTAXE : MAXIMIZE N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande MAXIMIZE est utilisée pour maximiser un FORM.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si le numéro N n'est pas le numéro d'un FORM.

EXEMPLE

' positionner FORM0

top 0,20:left 0,100

' dimensionner FORM0

width 0,200:height 0,400

wait 2000

caption 0,"maximisé"

maximize 0

wait 2000

caption 0,"minimisé"

minimize 0

wait 2000

caption 0,"normal"

normal 0
