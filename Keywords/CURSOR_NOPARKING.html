CURSOR_NOPARKING N

CURSOR_NOPARKING N

VISUALISE UN CURSEUR EN FORME DE PANNEAU D'INTERDICTION DE STATIONNER SUR L'OBJET SYSTÈME NUMÉRO N


  • Type : Commande
  • Paramètre : 1
  • Groupe : Objets Système


ACTION

La commande CURSOR_NOPARKING N visualise un curseur en forme de panneau d'interdiction de stationner (piloté par la souris) sur l'objet système numéro N.

L'objet système est du type : SCENE3D, BUTTON, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, MOVIE, TRACK_BAR, SCROLL_BAR, PROGRESS_BAR, SPIN, GRID, CONTAINER, MEMO_RICH, BUTTON_PICTURE, SCENE2D,PANEL, GRID_DRAW, CONTAINER_OPTION, SHAPE, HVIEWER, LED1,DIGIT1, SWITCH1, CONTAINER_TAB, SYNEDIT, CHART.

Remarque : le curseur peut être caché par la commande CURSOR_HIDE, et ramené à la forme standard par la commande CURSOR_DEFAULT.


SYNTAXE : CURSOR_NOPARKING N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande CURSOR_NOPARKING est utilisée pour visualiser un curseur (image de la souris) en forme de panneau d'interdiction de stationner sur un objet système.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet numéro N n'est pas du type : SCENE3D, BUTTON, EDIT, MEMO, COMBO, ALPHA, FORM, LIST, PICTURE, CHECK, OPTION, MOVIE, TRACK_BAR, SCROLL_BAR, PROGRESS_BAR, SPIN, GRID, CONTAINER, MEMO_RICH, BUTTON_PICTURE, SCENE2D,PANEL, GRID_DRAW, CONTAINER_OPTION, SHAPE, HVIEWER, LED1,DIGIT1, SWITCH1, CONTAINER_TAB, SYNEDIT, CHART.

EXEMPLE

CURSOR_NOPARKING.bas 
' créer  un container gris avec un curseur en panneau d'interdiction de stationner
container 1
color 1,200,200,200
cursor_noparking 1
