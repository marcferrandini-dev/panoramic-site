ITEM_SELECT N,L

SELECTIONNE L'ARTICLE NUMÉRO L DE L'OBJET SYSTÈME NUMÉRO N


  • Type: Commande
  • Paramètres: 2
  • Groupe: Objets Système


ACTION

La commande ITEM_SELECT N,L sélectionne la ligne (article) numéro L de l'objet système désigné par son numéro N.

L'objet système est du type : MEMO, MEMO_RICH, COMBO, LIST, SYNEDIT.

Remarque 1: la première ligne a le numéro 1.

Remarque 2: si L vaut 0, la sélection est annulée.


SYNTAXE : ITEM_SELECT N,L

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • L = numéro de ligne (entier ou réel). Ne doit pas être négatif. (0 est une déselection, 1 est la première ligne)

UTILISATION

  • La commande ITEM_SELECT est utilisée pour sélectionner une ligne d'un MEMO, un MEMO_RICH, un COMBO, un LIST, un SYNEDIT ou pour annuler la sélection.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si le numéro N n'est pas le numéro d'un : MEMO, MEMO_RICH, COMBO, LIST, SYNEDIT.
  • Si le numéro L n'est pas une expression correcte.
  • Si le numéro L est inférieur à 0.

EXEMPLE

' créer un LIST

list 1

' remplir le LIST avec 3 lignes

item_add 1,"c'est la ligne 1"

item_add 1,"c'est la ligne 2"

item_add 1,"c'est la ligne 3"

' attendre pendant 1 seconde

wait 1000

' sélectionner la deuxième ligne

item_select 1,2
