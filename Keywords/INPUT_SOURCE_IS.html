INPUT_SOURCE_IS N

INPUT_SOURCE_IS N

DÉSIGNE L'OBJET SYSTÈME NUMÉRO N COMME SOURCE DES DONNÉES


  • Type : Commande
  • Paramètre : 1
  • Groupe : Système


ACTION

La commande INPUT_SOURCE_IS N désigne l'objet système numéro N qui sera utilisé comme la SOURCE de données d'une commande INPUT.

L'objet système doit être du type : EDIT, COMBO, FORM.

Cet objet système devient l'objet système "source des données".

Par défaut, la source des données est le clavier et le numéro 0 est utilisé pour désigner le clavier (par défaut, la commande INPUT lit le clavier).


SYNTAXE : INPUT_SOURCE_IS N

  • N = numéro d'objet système (entier ou réel). Doit être supérieur à 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande INPUT_SOURCE_IS est utilisée pour lire par une commande INPUT un string appartenant à un objet système .

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si le numéro N n'est pas le numéro d'un : EDIT, COMBO, FORM.

EXEMPLE

INPUT_SOURCE_IS.bas 
dim a$
' créer un LIST
list 1
' le remplir avec un fichier
file_load 1,"data.txt"
' désigner ce LIST comme la source des données
input_source_is 1
' lire puis imprimer la première et la deuxième ligne du LIST
input a$:print "première ligne ="+a$
input a$:print "deuxième ligne ="+a$
