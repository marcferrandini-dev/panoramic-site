EXCEL_WRITE S1,S2

EXCEL_WRITE S1,S2

ÉCRIT S2 DANS LA CELLULE S1 DE LA FEUILLE COURANTE AVEC MICROSOFT EXCEL


  • Type : Commande
  • Paramètres : 2
  • Groupe : Excel


ACTION

La commande EXCEL_WRITE S1,S2 écrit le string S2 (texte ou variable string) dans la cellule définie par S1 dans la feuille de calcul courante de Microsoft Excel, s'il est en fonction.


SYNTAXE : EXCEL_WRITE S1,S2

  • S1 : chaîne de caractères représentant les coordonnées de la cellule (Exemple : "B2")
  • S2 : chaîne de caractères à écrire dans la cellule

UTILISATION

  • La commande est utilisée pour écrire dans une feuille de Microsoft Excel.

ERREUR

  • Si le logiciel d'Excel n'est pas lancé.
  • Si aucune feuille (fichier) n'est ouverte.

EXEMPLE

EXCEL_WRITE.bas 
' lancer le logiciel Excel
excel_start
' attendre 5 secondes
wait 5000
' créer un nouveau fichier
excel_file_new 1
' écrire "Salut" dans la cellule A1
excel_write "A1","Salut"
