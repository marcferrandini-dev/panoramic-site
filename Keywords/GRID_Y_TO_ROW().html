GRID_Y_TO_ROW(N,Y)

GRID_Y_TO_ROW(N,Y)

RETOURNE LE NUMÉRO DE LIGNE DU GRID NUMÉRO N À PARTIR DE LA COORDONNÉE Y


  • Type : Fonction
  • Paramètres : 3
  • Groupe : Objets Système


ACTION

La fonction GRID_Y_TO_ROW(N,Y) retourne le numéro de ligne du GRID numéro N à partir de la coordonnée Y.


SYNTAXE : Resultat=GRID_Y_TO_ROW(N,Y)

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.
  • Y = coordonnée (entier ou réel) dans l'objet système GRID.

UTILISATION

  • La fonction GRID_Y_TO_ROW() est utilisée pour connaître une ligne à partir de la coordonnée Y dans un GRID.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet numéro N n'existe pas.
  • Si le numéro N n'est pas le numéro d'un objet système : GRID.
  • Si la valeur Y est inférieure à 0.
  • Si la valeur Y n'est pas une expression correcte.

EXEMPLE

GRID_Y_TO_ROW().bas 
label col
caption 0,"CLIQUER DANS UNE CELLULE"
grid 1:width 1,400:height 1,200
on_click 1,col
end
col:
caption 0,"ligne = " + str$(grid_y_to_row(1,mouse_y_position(1)))+" colonne = " + str$(grid_x_to_column(1,mouse_x_position(1)))
return
