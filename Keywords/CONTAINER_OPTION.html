CONTAINER_OPTION N

CONTAINER_OPTION N

CRÉE UN OBJET SYSTÈME CONTAINER_OPTION ET LUI DONNE LE NUMÉRO N COMME RÉFÉRENCE


  • Type : Commande
  • Paramètre : 1
  • Groupe : Création Objets Système


ACTION

La commande CONTAINER_OPTION N crée un objet système CONTAINER_OPTION et lui donne un numéro N. Le numéro N sera utilisé pour désigner ce CONTAINER_OPTION.

Le CONTAINER_OPTION créé peut alors être utilisé par les commandes appropriées.

Le CONTAINER_OPTION est créé à la position (0,0) : c'est à dire TOP = 0 pixel et LEFT = 0 pixel, avec les dimensions WIDTH = 185 pixels et HEIGHT = 105 pixels.

Un CONTAINER_OPTION ne contient que des OPTIONS. Ces OPTIONs sont groupés : quand l'utilisateur coche un OPTION, tous les autres sont décochés. Deux OPTIONs ne peuvent être cochés en même temps.

La commande PARENT doit être utilisée pour grouper des OPTIONS dans un CONTAINER_OPTION.

Un CONTAINER_OPTION peut générer l'événement : ON_CLICK.

Remarque : par défaut, le CONTAINER_OPTION est créé sur le FORM numéro 0, mais un autre FORM peut être utilisé. Pour cela, créer un FORM par FORM N et lui envoyer les commandes par COMMAND_TARGET_IS N avant la création du CONTAINER_OPTION.


SYNTAXE : CONTAINER_OPTION N

  • N = numéro d'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • Un CONTAINER_OPTION est utilisé pour grouper des OPTIONs exclusives.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur ou égal à 0.
  • Si le numéro N est déjà utilisé pour un numéro d'objet système.

EXEMPLE

CONTAINER_OPTION.bas 
' crée un CONTAINER_OPTION avec la position et les dimensions par défaut
container_option 1
' le remplir avec 2 OPTIONS
option 2:parent 2,1
top 2,10:left 2,10:caption 2,"option 1"
option 3:parent 3,1
top 3,40:left 3,10:caption 3,"option 2"
