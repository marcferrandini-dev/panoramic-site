SHOW N

REND VISIBLE L'OBJET SYSTÈME NUMÉRO N


  • Type: Commande
  • Paramètre: 1
  • Groupe: Objets Système


ACTION

La commande SHOW N rend visible l'objet système désigné par son numéro N.

Dans le cas d'un SYNEDIT, la commande SHOW visualise les numéros de ligne (gouttière) après la commande SYNEDIT_TARGET_IS_GUTTER. Par défaut ou après la commande SYNEDIT_TARGET_IS_OBJECT, la commande SHOW rend visible l'objet SYNEDIT.


SYNTAXE : SHOW N

  • N = numéro de l'objet système (entier ou réel). Doit être plus grand que 0 et inférieur ou égal au nombre maximum permis d'objets systèmes.

UTILISATION

  • La commande SHOW est utilisée pour rendre visible un l'objet système qui était caché (par la commande HIDE), pour pouvoir l'utiliser.
  • La commande SHOW et sa commande inverse HIDE servent pour adapter un menu à un environnement.

ERREUR

  • Si le numéro N n'est pas une expression correcte.
  • Si le numéro N excède le nombre maximum permis d'objets systèmes.
  • Si le numéro N est inférieur à 0.
  • Si l'objet système numéro N n'existe pas.
  • Si l'objet numéro N est du type : MAIN_MENU, SOUND, OPEN_DIALOG, SAVE_DIALOG, DLIST, TIMER, MAIN_MENU_POP, OPEN_DIALOG_PIC, SAVE_DIALOG_PIC, SERIAL, IMAGE.

EXEMPLE

' créer un BUTTON

button 1

' attendre 1 seconde

wait 1000

' le cacher

hide 1

' attendre 1 seconde

wait 1000

' le visualiser de nouveau

show 1
